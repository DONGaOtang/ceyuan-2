# 创意思考交叉网络（Creative Intersection Network）

供 Step 3 纯发散时加载。核心一句话：**创意 = 锚点 × 可变域 → 反直觉组合。** 交叉网络是发散的**乘法引擎**——把「线性组装 N 个方向」升级成「碰撞出 N×M 个组合」。

> 关键约束：本网络**只发散，不评判**。它是「组合脚手架」，不是「检查枷锁」。任何「砍」的动作（同质性、主题推导）留在收敛和 Step 4，不许前移到这里。

## 一、结构：1 锚点 + 6 可变域 + 3 算子

```
锚点 × (热点 / 文化 / 情绪 / 跨界 / 感官 / 冲突) → 反直觉组合
```

### 锚点域（1 个，不变）

活动的「核心元素」——这场活动/品牌「我是谁」。策划人第一步锁定的东西：

| 活动类型 | 锚点（示例，动态判断，不硬套） |
|---|---|
| 发布会 | 悬念（One more thing） |
| 快闪 / 市集 | 稀缺 |
| 答谢会 / 私享会 | 专属 |
| 招商会 | 信任 |
| 年会 / 团建 | 归属 |

**用法**：发散前先问「这场活动的锚点是什么」——锚点不锁定，交叉就是乱撞。

### 可变域（6 个，动态生成，不硬编码穷举）

每个域里的「值」现场生成（热点实时拉、跨界现场调、情绪按受众判断），不是查清单：

| 域 | 关键词 | 值怎么来 |
|---|---|---|
| H 热点 | 及时性 | 实时拉当前热点，提取热点背后的「情绪」（不是热点本身） |
| C 文化 | 共鸣 | 圈层暗号、时代记忆、集体情绪、亚文化 |
| E 情绪 | 底层 | 受众此刻的焦虑/好奇/炫耀/归属/怕落单 |
| X 跨界 | 借机制 | 不相干行业解决同一动机的机制（游戏留存/宗教仪式/赌场逼单/综艺悬念…） |
| S 感官 | 五感 | 视觉/听觉/嗅觉/触觉/味觉的具体动作 |
| T 冲突 | 张力 | 反常识、反转、悖论、禁忌、留白 |

**克制原则**：起步用「锚点 + 3 个核心域（热点 / 情绪 / 跨界）」，其余域按需加。域越多越失控，宁精勿滥。

### 交叉算子（3 种）

1. **嫁接**（杜蕾斯法）：把外部要素「焊」到锚点上——拉伸、弯曲、组合、替换。
2. **双域碰撞**：锚点 × 任一变域，找反直觉交集。
3. **三域撞击**：锚点 × 两个变域，撞出「只有这个组合才有」的创意。

## 二、产出规则（守「发散收敛分离」）

- 每次交叉只产出「**一句核心概念 + 一句 self-steelman（为什么有意思）**」，**不做任何评判**。
- **反直觉优先**：不反直觉 = 平庸，弃。合理性交给 Step 4 对抗审查。
- **动机做第一道筛**：交叉产生的候选，先用 Step 2 的主判据粗筛，动机不对的不进发散列表。
- 交叉出 10–20 个候选，挑最反直觉的 3–5 个进收敛标注（Step 3 ④）。

## 三、热点借势铁律（及时性 + 不短命）

> **借势，不是蹭。** 提取热点背后的「情绪」当燃料，不贴热点标签。

- ❌ 蹭：「蹭某某明星塌房」——贴标签，短命，low。
- ✅ 借势：「塌房背后的集体情绪是对『真诚』的渴望」——提取情绪，喂进情绪域，长效。

**启动顺序**：跑交叉网络前，先按 `search-paths.md` 的热点源（微博热搜 / 抖音热榜 / 新榜日榜）拉当前热点 → 提取每个热点背后的情绪 → 把这些情绪喂进 H 热点域和 E 情绪域。

## 四、用法（四步）

1. **锁定锚点**：这场活动的核心元素是什么？
2. **拉热点 + 摸情绪**：实时拉当前热点，提取背后的情绪；判断受众此刻的情绪底层。
3. **交叉**：用「嫁接 / 双域碰撞 / 三域撞击」把锚点和变域撞出反直觉候选。
4. **挑反直觉**：从 10–20 个候选里挑最反直觉的 3–5 个，只给「一句概念 + 一句 self-steelman」，进收敛标注。

## 五、一个走通的例子（发布会）

- **锚点**：悬念。
- **实时拉热点**：假设当下热点是「某综艺靠淘汰赛翻红」。
- **嫁接**：悬念 × 综艺淘汰机制 → 「发布会不公布全貌，观众投票解锁下一个模块」。
- **三域撞击**：悬念 × 情绪(想炫耀) × 感官(嗅觉) → 「凭气味解锁的邀请函」。
- **双域碰撞**：悬念 × 冲突(留白) → 「发布会全程不出现产品正面，揭晓留到最后一秒」。

三个候选，一个锚点 × 三个变域。这就是乘法：组合爆炸，而不是线性组装。
