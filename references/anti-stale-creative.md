# 反陈旧审查与破常规组合

本文件解决一个问题：活动为什么会越写越旧。大模型默认会回到行业平均答案，所以必须用强制组合和反模板门禁逼它离开常规。

## 一、陈旧活动判定

命中任一条，进入高风险审查；根据真实目标核对后判定，不能只凭形式淘汰：
- 只换主题名，不换用户行为机制。
- 只有视觉包装，没有现场动作。
- 去掉包装后只剩签到、讲话、抽奖、合影。
- 用户没有非来不可的理由。
- 没有能说明本次场域价值的内容或动作。
- 有传播目标却没有可转述的内容、观点或画面。
- 没有使用用户反向信号、竞品空白或跨界机制。

判词：
- `通过`：机制、动作、传播、验证都成立。
- `修改后通过`：有新意但缺一个关键承接。
- `退回 Step 5 重撞`：方向有价值，但组合不够新。
- `淘汰`：只是旧流程换皮。

本审查在候选生成后的粗筛与成案中使用，保留既有先发散后收敛动作。常规形式不自动陈旧：有具体证据的演讲、内容充足的观看、必要而恰当的仪式可以成立。要攻击的是内容空洞和与需求无关，不是要求每场活动增加反转、竞猜、强制参与或公开传播。独立观看、安静交流和复演均按其真实价值判断。

## 二、反陈旧 7 问

每个创意进入成案前必须回答：

| 问题 | 判断标准 |
|---|---|
| 最像哪种旧套路 | 指出具体旧套路，不许写“暂无” |
| 用户是否见过 | 若见过，说明新的内容价值或机制差异；必要复演说明服务对象与可达价值 |
| 去掉包装还剩什么 | 若只剩流程名而没有具体内容、证据或体验，退回 |
| 非来不可理由 | 稀缺、身份、收益、关系、体验至少命中一个 |
| 只能现场发生动作 | 按现场/线上/混合场域说明不可被口号替代的观看、理解、关系或行动价值 |
| 平台传播画面 | 按已选渠道检查可传达的内容；闭门/禁拍活动检查获授权的纪要、成果或后续沟通 |
| 反向信号/空白/跨界 | 至少使用一种破局来源 |

## 三、六类破常规组合

Step 5 每次至少生成 6 类组合。

六类是发散方向，全部生成不等于全部采用；收敛时按动机与主判据选，不将六类硬塞进一个方案。时间结构变化不得用来伪造新内容，权力关系反转不得使核心信息被随机投票隐藏，感官异常不得喧宾夺主。筛下的创意留在过程记录，不扩成正式方案章节。

| 组合方向 | 公式 | 产出要求 |
|---|---|---|
| 用户吐槽反转 | 用户讨厌点 × 反向设计 | 把尴尬、无聊、麻烦、假大空反过来 |
| 跨界移植 | 同一动机 × 不相关行业机制 | 借游戏、综艺、宗教、餐饮、剧场等机制 |
| 平台玩法改造 | 活动锚点 × 平台有效玩法 | 把流行玩法改成该活动独有仪式 |
| 感官异常 | 活动目标 × 非视觉感官 | 用声音、气味、触感、味觉制造记忆点 |
| 权力关系反转 | 主办方说教 → 用户决定/解锁/共创 | 让参与者推动活动发生 |
| 时间结构打破 | 单日活动 → 连续任务/倒计时/分章节揭晓 | 把一次性活动变成可追更过程 |

## 四、创意闪卡增强格式

| 字段 | 写法 |
|---|---|
| 创意名 | 8-12 字，能被复述 |
| 常规做法 | 这个类型通常怎么做 |
| 为什么陈旧 | 用户为什么可能无感 |
| 破常规公式 | 六类组合中的哪一种 |
| 一句话概念 | 这场活动到底有什么不同 |
| 现场动作 | 至少一个互动、仪式、体验或内容动作 |
| 传播画面 | 用户拍什么，平台用户为什么停 |
| 解决的动机 | 对齐 Step 2 主判据 |
| 待验证假设 | 用户会因为什么报名/转发/留资/到场/购买 |
| 最小实验 | 预检或 AB 方式 |
| 最大执行风险 | 预算、合规、供应商、现场秩序等 |

## 五、例子

普通发布会：
- 常规：领导致辞、产品介绍、媒体提问。
- 破局：权力关系反转。
- 新机制：观众投票解锁发布顺序，关键模块由用户选择先看什么。

普通招商会：
- 常规：政策宣讲、样板案例、最后签约。
- 破局：时间结构打破 + 游戏机制。
- 新机制：按区域数据生成“城市战队”，现场争夺独家政策包。

普通年会：
- 常规：领导讲话、节目表演、抽奖。
- 破局：用户吐槽反转。
- 新机制：员工用证据争夺年度叙事权，把“领导总结”反转为“员工审判年度关键词”。

以上仅为发散示例，不是已验证的可执行答案。发布会若以专业判断为目标，投票不得打乱必要证据顺序；招商政策包必须有真实授权，不能虚构竞争与稀缺；年会“审判”是否合适取决于真实组织关系与已确认表达边界。每个入选方向都要补其实际内容、前后关系和完成状态，再按原流程进入交付与对抗审查。

## 六、禁止项

- 禁止只给主题名。
- 禁止把跨界行业照搬到活动现场。
- 禁止为了新奇牺牲主判据。
- 禁止把高执行难度创意直接判死，先给降级版。
- 禁止把“视觉高级”当作创意机制。
- 禁止把常规形式等同于内容无用，或把新奇度等同于用户价值；没有真实内容的“创新玩法”同样退回。
- 禁止以互动替代故事、以命名替代节目、以征集占位替代全部核心内容；应交的内容拟案仍由策划完成。
