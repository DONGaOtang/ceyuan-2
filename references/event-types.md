# 活动类型清单 + 案例锚点

> **本文件是「常用快速通道 + 案例锚点」，不是穷举清单。** 扩展定位看 `references/axes.md` 的四维推导轴——清单查得到就走清单，查不到走推导轴，两者并存、不互相取代；分类不等于专业内容已完备。

供 Step 0 判局、Step 2 行为改变、Step 5 创意机制时查阅。先定「目的」，再对表选类型。每个类型给三件套：**核心要素**（做对什么才成立；**也是横纵拆解的挂载点**——进入环节设计时，对这些要素逐个做横纵拆解，见 `creative-inputs.md` 三）、**成功判据**（怎么算成）、**翻车点**（最容易死在哪）。

**推导路径**：每个类型都落进 axes.md 的四维轴。选类型时内部标注它的推导路径（`[七状态] → [参与者/受益者] → [形态] → [时空]`），这是贯穿全流程的线索（Step 2/5 生成 → Step 7 攻击 → Step 8 验证 → `output/case-library/` 或用户指定复盘文档），但默认不进入阶段输出或正式方案正文。

本文件的“完备覆盖”指提供开放的定位入口，不是保证覆盖全部行业知识、专业标准、故事结构和文件规格。四维定位之后仍须按 `triage-router.md` 对应实际 brief，并按 `industries.md` 补专业内容。出现定位不清或内容缺口时保留缺口及影响，不因“已有一个类型”就判成案完成。

表内成功判据是候选指标，不是唯一目标或确定因果。依据本次任务确定主判据、口径、来源和观察周期；例如年会不能仅凭一次满意度就声称提高留存，公益不能只凭传播量声称产生受益成效，展览也不一律以留资衡量。章节所属类别表示常见用途，同一类型可以服务别的明确目的。

下列各节追加的“内容成立条件”用于既有 Step 4-6 深化与 Step 8/9 验收，不增加流程。每个选中类型需要能独立读懂的活动介绍、主要内容及其前后关系；故事可用情节、知识、体验、交易或关系的推进方式，不能只套起承转合词语。概念阶段写清完整构想，执行阶段再细到执行状态；未确认的节目、嘉宾、价格或合作一律保留状态。

案例锚点只作为待核实的检索起点与机制提示，文件中“标杆”“双赢”等是评价性速记，不能直接作为证据。对外引用前核对官方资料或可靠原始记录、时间、具体动作、结果口径与适用边界；无法核实的细节删去或标明，不据锚点编造效果。参考必须说清借鉴什么、舍弃什么以及为何适用于本项目。

## 一、品牌曝光（造声量、占心智）

| 活动类型 | 核心要素 | 成功判据 | 翻车点 |
|---|---|---|---|
| 发布会 | 悬念制造 + 峰值体验 + 媒体放大器 | 到场媒体数、报道量、二次传播 | 无新闻点、自嗨 |
| 快闪店 / 市集 | 稀缺感 + 打卡点 + 社交货币 | 人流、社媒传播量 | 只拍照不转化 |
| 展览 / 展会 | 参展：展位体验 + 获客线索；主办：招展 + 门票 + 行业影响力 | 参展看留资数、主办看招展量 | 参展流量大线索差、主办招不满展 |
| 媒体沟通会 | 信息密度 + 记者关系 | 正面报道数 | 无料可报 |
| 开放日 | 透明信任 + 实地体验 | 到场、口碑 | 变参观游 |
| 跨界联名 | 双品牌流量互导 | 联名款销量、传播 | 联名无化学反应 |
| 赞助 / 冠名 | 借别人的场子 + 场景绑定 | 曝光、赞助回报率、赞助商续约 | 硬植入违和、回报不落地 |

> **案例锚点**：苹果发布会（悬念制造 + 峰值体验标杆，「One more thing」制造好奇缺口）；瑞幸 × 茅台「酱香拿铁」（双品牌流量互导标杆，但热度衰减快，警惕「联名无化学反应」）。

| 类型 | 内容成立条件 |
|---|---|
| 发布会 | 一个明确发布事实对应问题、产品/项目证据、演示或揭晓、用户意义与下一步；有可用发布内容，不能只写“重磅揭幕” |
| 快闪店 / 市集 | 具体主题内容/品项、每个体验或摊位的参与方式、选择理由和路径关系；购物、观看、休息与离场能衔接 |
| 展览 / 展会 | 先区分商业参展、展会主办与艺术/知识展览：分别写展品讲解与商机、展商/观众匹配、策展命题与展项关系；不混用获客指标 |
| 媒体沟通会 | 有可核实的新信息、记者关心的问题、证据素材和问答；区分可公开与待核实内容 |
| 开放日 | 明确开放什么、每站看见何种真实工作/成果、谁解释、能问什么、最后形成何种理解 |
| 跨界联名 | 解释两方各贡献什么、共同产品/内容如何成立、用户如何体验与获得；没有联动实物或机制不能只拼 Logo |
| 赞助 / 冠名 | 说明品牌与活动内容的相关性、受众可感知的贡献、出现位置与实际权益；具体露出不能替代内容价值 |

## 二、销售转化（直接冲销量）

| 活动类型 | 核心要素 | 成功判据 | 翻车点 |
|---|---|---|---|
| 招商会 | 信任背书 + 政策刺激 + 逼单节奏 | 签约额 | 氛围没烘到签约 |
| 促销 / 节日营销 | 价格锚点 + 限时稀缺 | GMV | 伤品牌价盘 |
| 直播带货 | 主播信任 + 节奏逼单 | 成交额、ROI | 退货率高 |
| 品鉴会 | 体验种草 + 圈层渗透 | 现场下单、复购 | 变免费吃喝 |
| 限时体验店 | 试用即转化 | 转化率 | 体验后无承接 |

> **案例锚点**：李佳琦直播间（主播信任 + 节奏逼单标杆，「花西子 79 元」翻车暴露价格话术反噬）；双 11（价格锚点 + 限时稀缺极致，但「先涨后降」透支信任）。

| 类型 | 内容成立条件 |
|---|---|
| 招商会 | 合作对象的具体问题、项目/产品证据、合作机制、成本收益口径、问答和后续尽调；意向、合同与实际履约分开 |
| 促销 / 节日营销 | 为什么此时参与、实际商品/服务、权益计算示例、领取使用路径和限制；期限与库存需要真实依据 |
| 直播带货 | 具体货盘顺序、每品卖点证据、演示内容、互动问答、价格说明及下单/售后承接；不能以“逼单”代替有效信息 |
| 品鉴会 | 品项选择、品鉴顺序、风味/工艺或性能解释、对比体验和交流问题；参与者能说出体验差异 |
| 限时体验店 | 具体使用任务、体验前预期、操作与反馈、体验后判断和购买/预约承接；不只有试用台与促销口号 |

## 三、关系维护（拉近、留人、答谢）

| 活动类型 | 核心要素 | 成功判据 | 翻车点 |
|---|---|---|---|
| 答谢会 | 情感浓度 + 专属感 | 续约/复购意愿 | 像走流程的饭局 |
| 私享会 / 沙龙 | 高密度圈层 + 干货 | 到场质量、后续合作 | 变广告 |
| 酒会 / 晚宴 | 松弛 + 人脉对接 | 对接质量 | 寒暄无实质 |
| 粉丝见面会 | 宠粉 + 情感峰值 | 到场、传播 | 流程敷衍伤粉 |
| 周年庆 | 情怀 + 里程碑叙事 | 传播、忠诚度 | 自嗨无用户视角 |
| 会员日 / 私域运营 | 持续运营 + 权益 + 复购钩子 | 复购率、会员活跃度 | 变群发广告、薅完就走 |

> **案例锚点**：罗振宇「时间的朋友」跨年演讲（高密度干货 + 圈层归属的私享会标杆）；小米米粉节（宠粉 + 情感峰值，粉丝参与产品决策）。

| 类型 | 内容成立条件 |
|---|---|
| 答谢会 | 被感谢的真实贡献、具体人物/合作故事、对等回应和后续关系动作；感谢不能只剩主持串词 |
| 私享会 / 沙龙 | 一项值得交流的问题、可信引入内容、能讨论的具体问题、发言衔接和可带走结论 |
| 酒会 / 晚宴 | 主人邀约理由、同席/交流主题、介绍方式与关系连接；用自然交往节奏，不强编完整剧情 |
| 粉丝见面会 | 主体与粉丝共有的具体内容、参与机会、互动问题、回应和情绪收束；拟邀人物保留状态 |
| 周年庆 | 可核实的里程碑、参与者在历史中的位置、当下变化与下一段承诺；不能只有大事记与数字 |
| 会员日 / 私域运营 | 本期权益与内容、会员的具体任务和反馈、前后周期连接；下次参与理由不能只靠重复优惠 |

## 四、内部凝聚（稳军心）

| 活动类型 | 核心要素 | 成功判据 | 翻车点 |
|---|---|---|---|
| 年会 | 归属感 + 表彰 + 放松 | 员工满意度、留存 | 尬、像加班 |
| 团建 | 破冰 + 协作 | 团队氛围 | 强制尴尬、占休息 |
| 颁奖典礼 | 荣誉感 + 标杆叙事 | 激励效果 | 只发奖无故事 |
| 员工大会 | 方向共识 + 士气 | 共识度 | 变汇报大会 |

> **案例锚点**：阿里年会（归属感 + 表彰标杆，但大型年会易陷入表演化自嗨）。

| 类型 | 内容成立条件 |
|---|---|
| 年会 | 组织此刻要说的话、真实贡献/经历、节目或互动的具体内容、表彰与未来方向如何接续 |
| 团建 | 具体协作任务、信息/资源分工、参与与退出方式、复盘问题；娱乐目标可直接成立，不必虚构组织疗效 |
| 颁奖典礼 | 奖项理由、获奖者可核实贡献、呈现方式、颁奖动作和获奖回应；公平性与故事真实性同时成立 |
| 员工大会 | 具体方向/决定、证据解释、员工受影响之处、问答及会后行动；不能只写领导讲话时段 |

## 五、招商融资（要钱、要资源）

| 活动类型 | 核心要素 | 成功判据 | 翻车点 |
|---|---|---|---|
| 路演 | 故事 + 数据 + 可信 | 跟进意向、TS | 讲不清商业模式 |
| 行业峰会 / 论坛 | 议题高度 + 资源聚集 | 参会层级、对接 | 凑人场、无干货 |

> **案例锚点**：YC Demo Day（路演标杆，故事 + 数据 + 可信三要素齐备）。

| 类型 | 内容成立条件 |
|---|---|
| 路演 | 具体问题、方案/产品、验证结果与边界、商业机制、明确合作请求及问答；数据和成果有来源 |
| 行业峰会 / 论坛 | 总议题拆成真实问题链，每场说明要解决什么、持何种证据/观点、如何讨论、输出何种结论并传给下一场 |

学术研讨、技能培训和专业工作坊等未单列类型，仍按既有四维定位和上述会议内容要求适配：补知识/技能目标、先备条件、材料或案例、示范/练习、反馈与成果检验，不因缺少专门行就只交论坛议程。艺术演出等其他长尾类型同理，不能用“最近的例子”替代其专业内容。

## 六、内容传播（造内容、破圈）

| 活动类型 | 核心要素 | 成功判据 | 翻车点 |
|---|---|---|---|
| 挑战赛 / 赛事 | 低参与门槛 + 裂变 | UGC 量、话题度 | 没人参与 |
| 专业竞技 / 赛事 | 观赏性 + 胜负悬念 + 转播 | 观赛量、赞助额 | 冷场、水平不够 |
| 音乐会 / 演出 | 情绪峰值 + 记忆锚点 | 到场、传播 | 体验差 |
| 公益 / 慈善 | 价值观 + 社会认同 | 口碑、传播 | 被质疑作秀 |

> **案例锚点**：冰桶挑战（低门槛参与 + 裂变极致，公益 + 社交货币双赢，但被质疑作秀）；网易云音乐地铁乐评（情绪峰值 + UGC 沉淀标杆）。

| 类型 | 内容成立条件 |
|---|---|
| 挑战赛 / 赛事 | 具体挑战任务、完整规则、有效参与示例、评判/结果、展示与传播关系；UGC样例不能只给话题标签 |
| 专业竞技 / 赛事 | 赛制、轮次衔接、成绩判定、申诉和观赛解释；项目专业规则由适用组织/官方版本核实 |
| 音乐会 / 演出 | 演出主题、作品/节目实际内容、段落与情绪关系、观众如何进入和结束；戏剧需角色/行动/变化，曲目或剧目未定时标选作条件 |
| 公益 / 慈善 | 受益者的真实问题、资源如何变成具体服务、参与者实际动作、结果与披露方式；故事必须有依据和必要授权 |

## 七、危机应对（灭火、挽回声誉）— 推导路径：认知 → 公众/品牌 → 接受 → 线下/混合

| 活动类型 | 核心要素 | 成功判据 | 翻车点 |
|---|---|---|---|
| 道歉发布会 | 真诚认错 + 具体补救 + 情绪克制 | 舆论转向、二次伤害消除 | 辩解、甩锅、表演式道歉 |
| 媒体澄清会 | 事实澄清 + 证据 + 第三方背书 | 误传消除、权威报道 | 越描越黑、回避核心 |
| 用户沟通会 | 倾听 + 补偿 + 承诺整改 | 投诉下降、复购回暖 | 敷衍、拖延、无实质补偿 |

> **案例锚点**：海底捞「老鼠门」道歉（真诚认错 + 具体整改，危机公关正面标杆）；三星 Note7 中国区区别对待（危机应对失败反面案例）。

| 类型 | 内容成立条件 |
|---|---|
| 道歉发布会 | 已确认事实、责任口径、具体补救与期限、可验证进展及问答；未知原因不编完整叙事填补 |
| 媒体澄清会 | 逐项争议信息、相应证据与限定范围、发布主体与问题回应；第三方身份和结论有依据 |
| 用户沟通会 | 真实问题分类、倾听和记录方式、可授权答复、处理路径与反馈期限；不以交流气氛代替解决 |

## 八、仪式确认（确认身份/资格）— 推导路径：身份 → 组织+公众/组织 → 仪式 → 线下/单次

| 活动类型 | 核心要素 | 成功判据 | 翻车点 |
|---|---|---|---|
| 开工 / 奠基 / 竣工 / 投产仪式 | 仪式感 + 权威背书 + 传播 | 到场领导级别、报道量、里程碑确立 | 只走形式、无传播 |
| 揭牌 / 成立仪式 | 符号化动作 + 意义宣告 | 传播、权威到场 | 冷清、规格不够 |
| 签约 / 授牌 / 颁证仪式 | 事实确认 + 背书 + 记录 | 签约效力、传播、关系巩固 | 变摆拍、无后续 |

> **案例锚点**：特斯拉上海工厂奠基（政府高层背书 + 全球传播，政企仪式标杆）。

| 类型 | 内容成立条件 |
|---|---|
| 开工 / 奠基 / 竣工 / 投产仪式 | 该里程碑真实意味着什么、项目证据、仪式动作与状态一致、谁作何种确认；不能混用开工与投产事实 |
| 揭牌 / 成立仪式 | 新主体/机构的职责、关系、成立依据和下一步服务；名称与授权未确认不能写既成事实 |
| 签约 / 授牌 / 颁证仪式 | 明确签署或授予对象、文件效力/资格边界、主体权限和后续兑现；舞台动作不等于法律或商业结果 |

## 九、人才获取（招人、雇主品牌）— 推导路径：资源 → 潜在人才/组织 → 接受+参与 → 混合

| 活动类型 | 核心要素 | 成功判据 | 翻车点 |
|---|---|---|---|
| 校招宣讲会 | 岗位吸引力 + 现场投递 + 雇主故事 | 简历量、offer 接受率 | 画饼、信息不对称 |
| 招聘开放日 | 真实工作场景 + 员工现身说法 | 简历量、入职转化 | 变参观、无转化 |
| 雇主品牌活动 | 价值观输出 + 在职体验 | 雇主口碑、招聘成本下降 | 自嗨、与真实差距大 |

> **案例锚点**：宝洁校园招聘（雇主品牌 + 校招宣讲标杆）。

| 类型 | 内容成立条件 |
|---|---|
| 校招宣讲会 | 真实岗位与工作任务、团队/成长案例、要求与关键条件、候选人问答和投递后反馈 |
| 招聘开放日 | 可看到的真实工作、员工如何讲解、岗位体验/交流、适配判断与应聘路径 |
| 雇主品牌活动 | 具体员工经历与证据、候选人在意的问题、参与反馈；有叙事但不伪造员工证言或工作体验 |

## 十、政企对接（要政策、要地、要背书）— 推导路径：关系/资源 → 政府/组织 → 仪式+连接 → 线下/单次

| 活动类型 | 核心要素 | 成功判据 | 翻车点 |
|---|---|---|---|
| 招商引资大会 | 产业叙事 + 政策 + 逼单 | 签约项目、落地率 | 凑数、签约不落地 |
| 政企签约 / 战略合作 | 高规格 + 双赢叙事 + 背书 | 签约效力、政策资源到位 | 只签不做、无实质 |
| 考察接待 | 实力展示 + 汇报 + 关系经营 | 领导满意、政策/资源获取 | 形式化、无后续跟进 |

> **案例锚点**：合肥「风投之城」招商引资（政府主导 + 产业链招商标杆）。

| 类型 | 内容成立条件 |
|---|---|
| 招商引资大会 | 区域/产业具体机会、真实项目条件、政策适用边界、企业问题与对接议题、后续尽调推进 |
| 政企签约 / 战略合作 | 双方各自要解决的问题、合作事项、资源责任、事实效力与落实路径；“高规格”不能代替实质内容 |
| 考察接待 | 考察目标、每站证据和讲解重点、问题收集、会谈议题与后续答复；不把走访站点清单当成果 |

## 使用规则

1. **先定目的，再选类型**。目的没定清就选类型，等于先射箭再画靶。
2. **清单 vs 推导轴的分工**：本清单是「快速通道」，覆盖常见类型；查不到的类型（冷门、新兴），用 `axes.md` 四维推导轴现场定位，再回本表寻找有依据的案例锚点。**两者用于检查遗漏，不保证现实需求穷尽；相近案例不能替代本次专业核实。**
3. **可混搭，别贪多**。一场活动主类型 1 个，辅类型 ≤2 个，多了现场就散。
4. **翻车点即 Step 7 对抗审查的靶子**。选完类型，把它的翻车点直接送进对抗审查；同时把「推导路径」也送进对抗。类型定位错了，方案全错；完整推导默认进思考过程文件。
5. **长闭环**：活动结束后，把本次「目标 vs 实际 + 翻车点 + 推导路径断点 + 创意类型」追加到 `output/case-library/` 或用户指定复盘文档，供下次检索。跑测偏差写入 `output/run-reviews/`，方法论改进建议写入 `output/improvement-log/`。不得直接写回本 reference 文件。

一主类型、最多两辅类型限制的是总策略与参考加载，不是删减用户已经要求的子活动。复合节庆、年度项目、展会大会按已要求的单元记录 `单元任务—参与对象—实质内容—与上一/下一单元关系—共享资源—交付去向`；主路由统筹，子单元按其实际类型检验，避免三种模板拼接或遗漏其他真实需求。无需为每个单元重复跑一套独立状态机，实质变化回到现有受影响步骤处理。

类型适配通过的最低证据，是每个主要单元能让不在场的读者回答：这里具体发生什么、参与者能看见/听到/做什么、获得什么、为何放在这里、怎样结束或转入下一段。议题名、节目名、时长和“沉浸互动”等形容词均不能单独满足；删掉主题名仍只剩通用流程，说明内容未开发完成。轻量活动可以用短段落写足这些信息，不强制长篇故事、独立概念文件或专业脚本。
