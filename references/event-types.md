# 活动类型要素清单（按目的归类）

供 Step 2 确定活动形式时查阅。先定「目的」，再对表选类型。每个类型给三件套：**核心要素**（做对什么才成立）、**成功判据**（怎么算成）、**翻车点**（最容易死在哪）。

## 一、品牌曝光（造声量、占心智）

| 活动类型 | 核心要素 | 成功判据 | 翻车点 |
|---|---|---|---|
| 发布会 | 悬念制造 + 峰值体验 + 媒体放大器 | 到场媒体数、报道量、二次传播 | 无新闻点、自嗨 |
| 快闪店 / 市集 | 稀缺感 + 打卡点 + 社交货币 | 人流、社媒传播量 | 只拍照不转化 |
| 展览 / 展会 | 展位体验 + 获客线索 | 留资数、商务对接量 | 流量大线索差 |
| 媒体沟通会 | 信息密度 + 记者关系 | 正面报道数 | 无料可报 |
| 开放日 | 透明信任 + 实地体验 | 到场、口碑 | 变参观游 |
| 跨界联名 | 双品牌流量互导 | 联名款销量、传播 | 联名无化学反应 |

> **案例锚点**：苹果发布会（悬念制造 + 峰值体验标杆，「One more thing」制造好奇缺口）；瑞幸 × 茅台「酱香拿铁」（双品牌流量互导标杆，但热度衰减快，警惕「联名无化学反应」）。

## 二、销售转化（直接冲销量）

| 活动类型 | 核心要素 | 成功判据 | 翻车点 |
|---|---|---|---|
| 招商会 | 信任背书 + 政策刺激 + 逼单节奏 | 签约额 | 氛围没烘到签约 |
| 促销 / 节日营销 | 价格锚点 + 限时稀缺 | GMV | 伤品牌价盘 |
| 直播带货 | 主播信任 + 节奏逼单 | 成交额、ROI | 退货率高 |
| 品鉴会 | 体验种草 + 圈层渗透 | 现场下单、复购 | 变免费吃喝 |
| 限时体验店 | 试用即转化 | 转化率 | 体验后无承接 |

> **案例锚点**：李佳琦直播间（主播信任 + 节奏逼单标杆，「花西子 79 元」翻车暴露价格话术反噬）；双 11（价格锚点 + 限时稀缺极致，但「先涨后降」透支信任）。

## 三、关系维护（拉近、留人、答谢）

| 活动类型 | 核心要素 | 成功判据 | 翻车点 |
|---|---|---|---|
| 答谢会 | 情感浓度 + 专属感 | 续约/复购意愿 | 像走流程的饭局 |
| 私享会 / 沙龙 | 高密度圈层 + 干货 | 到场质量、后续合作 | 变广告 |
| 酒会 / 晚宴 | 松弛 + 人脉对接 | 对接质量 | 寒暄无实质 |
| 粉丝见面会 | 宠粉 + 情感峰值 | 到场、传播 | 流程敷衍伤粉 |
| 周年庆 | 情怀 + 里程碑叙事 | 传播、忠诚度 | 自嗨无用户视角 |

> **案例锚点**：罗振宇「时间的朋友」跨年演讲（高密度干货 + 圈层归属的私享会标杆）；小米米粉节（宠粉 + 情感峰值，粉丝参与产品决策）。

## 四、内部凝聚（稳军心）

| 活动类型 | 核心要素 | 成功判据 | 翻车点 |
|---|---|---|---|
| 年会 | 归属感 + 表彰 + 放松 | 员工满意度、留存 | 尬、像加班 |
| 团建 | 破冰 + 协作 | 团队氛围 | 强制尴尬、占休息 |
| 颁奖典礼 | 荣誉感 + 标杆叙事 | 激励效果 | 只发奖无故事 |
| 员工大会 | 方向共识 + 士气 | 共识度 | 变汇报大会 |

> **案例锚点**：阿里年会（归属感 + 表彰标杆，但大型年会易陷入表演化自嗨）。

## 五、招商融资（要钱、要资源）

| 活动类型 | 核心要素 | 成功判据 | 翻车点 |
|---|---|---|---|
| 路演 | 故事 + 数据 + 可信 | 跟进意向、TS | 讲不清商业模式 |
| 行业峰会 / 论坛 | 议题高度 + 资源聚集 | 参会层级、对接 | 凑人场、无干货 |

> **案例锚点**：YC Demo Day（路演标杆，故事 + 数据 + 可信三要素齐备）。

## 六、内容传播（造内容、破圈）

| 活动类型 | 核心要素 | 成功判据 | 翻车点 |
|---|---|---|---|
| 挑战赛 / 赛事 | 低参与门槛 + 裂变 | UGC 量、话题度 | 没人参与 |
| 音乐会 / 演出 | 情绪峰值 + 记忆锚点 | 到场、传播 | 体验差 |
| 公益 / 慈善 | 价值观 + 社会认同 | 口碑、传播 | 被质疑作秀 |

> **案例锚点**：冰桶挑战（低门槛参与 + 裂变极致，公益 + 社交货币双赢，但被质疑作秀）；网易云音乐地铁乐评（情绪峰值 + UGC 沉淀标杆）。

## 使用规则

1. **先定目的，再选类型**。目的没定清就选类型，等于先射箭再画靶。
2. **可混搭，别贪多**。一场活动主类型 1 个，辅类型 ≤2 个，多了现场就散。
3. **翻车点即 Step 4 对抗审查的靶子**。选完类型，把它的翻车点直接送进对抗审查。
4. **长闭环**：活动结束后，把本次「目标 vs 实际 + 翻车点 + 创意类型」追加到对应活动类型的案例锚点里，供下次检索。不写回 = 这次白做。
