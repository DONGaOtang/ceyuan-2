# 新媒体 Campaign 模块

当活动涉及线上传播、平台内容、达人、UGC、直播、私域或长期传播时，不能只写“传播设计”，必须升级成 campaign 系统。

## 一、判断是否触发

命中任一条件即触发：
- 活动主要依赖小红书、抖音、视频号、公众号、微博、B站、私域传播。
- 目标包含报名、收藏、转发、评论、留资、购买、复购。
- 活动要产出短视频、图文、直播切片、达人内容或 UGC。
- 活动不是单日结束，而是有预热、爆发、长尾。

## 二、平台矩阵与平台语法

不能只列“发小红书、发抖音”。每个平台必须说明它在本次活动里承担什么角色、使用什么内容语法、承接什么用户动作。

| 平台 | 平台角色 | 内容语法 | 不适合什么 | 可测变量 | 活动资产形式 |
|---|---|---|---|---|---|
| 小红书 | 种草、搜索、收藏、攻略、体验证明 | 真实体验、清单攻略、可复制生活方式、细节图、避坑/值不值 | 硬广通稿、空泛发布、强官方口吻 | 标题、封面、关键词、收藏理由 | 图文笔记、探店笔记、攻略清单、打卡路线 |
| 抖音 | 前 3 秒抓注意、情绪扩散、现场爆点 | 冲突、反转、视听刺激、强情绪、可转述梗 | 长解释、纯官方流程回顾、弱画面内容 | 开头 3 秒、BGM、冲突点、CTA | 短视频、挑战、直播切片、达人探场 |
| 视频号 | 私域信任、直播预约、熟人转发 | 稳定口径、可信背书、社群承接、公众号联动 | 过度娱乐化、陌生流量硬冲 | 直播预约文案、转发话术、社群提醒 | 直播预约、转发海报、社群素材、回放 |
| 公众号 | 官方解释、深度承接、报名与复盘归档 | 背景、逻辑、长文、报名链接、复盘、领导/品牌口径 | 只追即时热度、碎片化梗 | 标题、导语、报名 CTA、长图结构 | 推文、长图文、报名页、复盘稿 |
| 微博 | 公共议题、热点扩散、媒体/KOL 讨论 | 话题、观点、事件节点、媒体扩散 | 私密高端、强转化闭环 | 话题名、媒体标题、KOL 观点 | 话题页、热搜借势、媒体通稿、图文短帖 |
| B站 | 深内容、幕后、测评、专业解释 | 长视频、幕后故事、专业评测、弹幕互动 | 低信息密度硬广、纯促销 | 视频标题、章节结构、封面、互动问题 | 长视频、幕后纪录、测评、嘉宾深访 |
| 私域 | 邀约、转化、复购、分层运营 | 熟人信任、利益点、倒计时、销售跟进、群内答疑 | 只做品牌自嗨、不分层群发 | 邀约话术、福利、提醒节奏、销售 CTA | 群海报、销售话术、福利卡、回访模板 |

硬规则：不要全平台铺开。按人群和目标选择 2-4 个主平台，其余作为辅助。

输出要求：每个被选平台都要写 `为什么用它 / 用什么语法 / 不适合做什么 / 测什么 / 产出什么资产`。如果只能写平台名，说明还没想清楚。

## 三、内容节奏

| 阶段 | 目标 | 内容 |
|---|---|---|
| 预热期 | 造期待、测钩子、拉报名 | 悬念海报、邀约话术、达人预告、报名页 |
| 爆发期 | 放大现场、推动互动 | 现场短视频、直播、话题挑战、实时照片 |
| 长尾期 | 沉淀资产、复盘转化 | 复盘稿、金句切片、用户故事、销售资料包 |

每个阶段都要写：目标、内容形式、平台、责任人、发布时间、指标。

## 四、内容资产清单

正式方案至少列出：
- 短视频脚本：3-5 个选题方向。
- 图文选题：3-5 个标题方向。
- 直播切片：关键环节和可剪点。
- 嘉宾金句：可传播语句收集机制。
- UGC 任务：用户拍什么、发什么、带什么话题。
- 官方复盘：对外稿、对内汇报稿、销售跟进素材。

## 四点五、传播外包接口

当传播由外部公司、达人/KOL 团队、媒体公司或甲方传播部门承接时，不能只写内容资产清单，必须写“可交接 brief”。

日更型活动：

| 每日交付物 | 数量 | 格式 | 来源模块 | 交付时间 | 责任人 |
|---|---:|---|---|---|---|
| 今日地图/导览图 | 1 张 | 海报/长图/图文底稿 | 动线/地图 | 每日固定时间 |  |
| 现场短视频素材 | 3-5 条 | 原片索引/粗剪/字幕稿 | 峰值事件/现场动作 | 当日或次日 |  |
| 金句/评论摘录 | 3-5 条 | 文案卡/字幕稿 | 嘉宾/主持/观众 | 当日 |  |
| UGC/观众反馈精选 | 5-10 条 | 文本/截图授权记录 | 互动/问卷/私域 | 当日或次日 |  |
| 音频/直播切片 | 1-2 条 | 音频/视频片段 | 电台/直播/访谈 | 次日 |  |
| 明日预告文案 | 1 组 | 标题、正文、CTA | 排期/节目单 | 前一晚 |  |

非日更活动按预热期、活动日、活动后 72 小时拆交付包。每个交付包都要写清素材来源、审核人和最晚交付时间。

## 五、用户动作链

不要只写“提升传播”。要写用户下一步动作：

```
看到内容 → 产生兴趣 → 点击/收藏/评论 → 报名/预约 → 到场/观看 → 互动/打卡 → 留资/购买 → 分享/复购
```

每个动作都要有承接物：
- 点击：标题、封面、CTA。
- 报名：报名页、福利、名额、提醒。
- 到场：日历提醒、社群、保证金、专属权益。
- 打卡：现场画面、身份凭证、限定内容。
- 转化：优惠、销售话术、会后跟进。

## 六、传播钩子

每个创意必须回答：
- 用户发出去能显得更有趣、更内行、更有身份，还是更接近某个圈层？
- 这个画面是否只有现场能拍到？
- 用户一句话怎么解释“我为什么来”？
- 平台用户刷到后，前 3 秒为什么停？

## 七、AB / 预检接口

优先测试：
- 海报标题。
- 报名页主张。
- 邀约话术。
- 短视频开头 3 秒。
- CTA。
- 话题名。

执行规则见 `ab-test-routing.md`。样本不足时标“方向性预检”。
