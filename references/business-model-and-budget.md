# 经营模型与预算

本文件用于 Step 3 经营模型、Step 6 交付系统、Step 8 成案。目标是让活动的“钱、资源、回报、降级”说得清。

## 一、触发条件

命中任一项必须加载：

- 用户提供预算、报价、成本、收入、ROI、赞助、票务、销售线索、订货、GMV。
- 乙方提案、招商赞助、老板过会、年度项目、大型活动。
- 用户问“为什么值”“怎么省钱”“预算怎么分”“钱花在哪”。

## 二、成本模型

| 成本类型 | 包含 | 输出要求 |
|---|---|---|
| 固定成本 | 策划、设计、场地基础、基础搭建、基础 AV、项目管理 | 不随人数变化，先锁不可砍项 |
| 可变成本 | 餐饮、礼品、座位、胸卡、物料、人员加班 | 按人头或数量计算 |
| 半可变成本 | 摄影摄像、传播、嘉宾、安保、搭建升级 | 给档位或区间 |
| 应急金 | 天气、供应商、物料损耗、临时加项 | 默认 10%，户外/大型/多城可提高 |

所有金额必须标来源：用户给定、供应商报价、历史数据、benchmark、暂定假设。

## 三、三档预算

正式方案建议给三档：

| 档位 | 定义 | 适用 | 不能牺牲 |
|---|---|---|---|
| Lean | 最小可行活动 | 钱少、时间短、先试水 | 主目标、合规、安全、核心体验 |
| Base | 推荐方案 | 大多数正式活动 | 主叙事、峰值、数据采集、风险预案 |
| Stretch | 增强方案 | 高预算、年度项目、竞标 | 年度主场面、传播资产、体验精度 |

## 四、回报模型

按活动动机选择，不要全塞：

| 回报类型 | 可证明方式 |
|---|---|
| 票务收入 | 票价 × 售票数，区分早鸟/标准/团购/赠票 |
| 赞助收入 | tier 价格 × 预计赞助数，区分确认和 pipeline |
| 销售线索 | MQL/SQL 数、商机金额、会后会议数、CRM 回填 |
| 渠道订货 | 签约额、订货额、首款比例、回款周期 |
| 品牌资产 | 内容资产、搜索占位、媒体报道、UGC、私域标签 |
| 汇报价值 | 领导到场、媒体口径、政策/机构背书、内部共识 |

## 五、预算价值架构

高预算、老板过会、乙方提案不要只列明细，先解释价值系统：

| 系统 | 包含模块 | 解决的问题 | 预算占比 | 价值证明 |
|---|---|---|---|---|
| 进入系统 | 邀约、报名、入口、导览、动线 | 用户如何进入体验 |  | 到场质量、投诉下降 |
| 发生系统 | 峰值事件、互动、仪式、内容 | 为什么必须到现场 |  | 参与率、停留、传播 |
| 资产系统 | 影像、UGC、媒体、复盘、CRM | 活动结束后留下什么 |  | 内容数量、线索、报告 |
| 保障系统 | 项目管理、安全、合规、应急 | 怎么保证不翻车 |  | 准时交付、事故率 |

## 六、降级模型

每个方案必须准备降级：

| 触发 | 降级动作 | 保留底线 |
|---|---|---|
| 钱少 | 砍装饰、砍低效物料、降搭建规格 | 不砍安全、主场面、数据采集 |
| 时间短 | 并行审批/供应商/传播，减少定制物料 | 不跳过彩排和合规 |
| 人少 | 缩场地、改邀请制、做高质量小场 | 不硬凑人场 |
| 审批慢 | 准备保守版主题、备选场地、替代物料 | 不碰合规红线 |
| 到场低 | 加强 1v1 邀约、候补池、直播/内容转化 | 不伪造热闹 |

## 七、预算自检

- 分项加总必须等于总额。
- 应急金必须单列。
- 不可砍项必须解释原因。
- 可砍项必须说明砍掉损失什么。
- 乙方方案要区分服务费、第三方费用、可选项和不包含项。
