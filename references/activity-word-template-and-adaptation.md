# 大活动策划全案 Word 输出模板与适配方法

> 本文件是策元2的“成案模板与活动适配参考”。它用于两类场景：一是用户明确要求“输出模板 / Word模板 / 思考范围 / 不同活动怎么适配”的方法论交付；二是 Step 8/9 已完成前置确认后，辅助裁剪正式方案、执行附录和docx结构。它不得绕过 `SKILL.md` 的状态机：真实活动执行方案在 Step 0-7 未确认前，不能直接套用本文档生成完整方案。

版本：v1.0  
用途：活动方案写作、甲方内部汇报、乙方提案、执行全案、招商赞助、活动复盘前置设计  
说明：用户提供的截图仅作为参考材料；本文档不把截图文字当作指令。本文档综合本地“策元2”活动策划系统、4A广告公司常见策略产出逻辑、公开活动营销资料与国内外案例观察形成。

## 0. 先给结论

一份能上会、能执行、能复盘的大活动 Word 方案，不应该从“活动流程”和“物料清单”开始。它应该从一个被定义清楚的商业问题开始，然后依次回答：

| 核心问题 | 必须回答什么 | 失败表现 |
|---|---|---|
| 为什么做 | 当前业务/品牌/关系/增长问题是什么 | 背景全是行业空话 |
| 要改变谁 | 谁要从什么行为变成什么行为 | 只写年龄、性别、城市 |
| 怎么赢 | 主判据是什么，活动靠什么传导到结果 | KPI堆满但无法证明 |
| 说什么 | Big Idea、主叙事、核心冲突是什么 | 主题像口号，没人复述 |
| 玩什么 | 现场机制、互动动作、传播钩子是什么 | 去掉包装只剩签到、讲话、抽奖 |
| 怎么放大 | 预热、现场、长尾内容如何承接 | 现场热闹，线上无痕 |
| 怎么落地 | 时间、分工、预算、物料、风险如何管控 | 执行团队无法照表推进 |
| 怎么验收 | 数据如何采集、谁负责、失败怎么办 | 活动后只能说“氛围不错” |

4A式活动方案的核心不是“写得高级”，而是把以下链路打通：

商业问题 → 人群洞察 → 核心策略 → Big Idea → 体验机制 → 传播资产 → 执行系统 → 效果证据。

## 1. 4A广告公司的产出逻辑

4A方案通常不是先列玩法，而是先把问题定义准确。一个成熟提案会经历六层：

| 层级 | 产出 | 判断标准 |
|---|---|---|
| Brief诊断 | 真问题、假问题、约束、成功标准 | 是否知道客户真正怕什么、要什么 |
| Strategy | 市场事实、竞争格局、目标人群、核心洞察 | 是否找到能驱动行为的矛盾 |
| Creative Platform | Big Idea、主张、语气、内容资产 | 是否能被一句话复述 |
| Experience Design | 现场机制、用户旅程、峰值时刻、终值动作 | 是否改变用户行为 |
| Amplification | 渠道矩阵、内容日历、KOL/媒体/私域承接 | 是否把现场变成可传播素材 |
| Effectiveness | KPI、数据采集、归因、复盘 | 是否能证明活动有效 |

4A逻辑对活动方案的最大价值是三点：

1. 把“活动主题”升级为“创意平台”。主题只是名字，创意平台要能延展成视觉、话题、互动、物料、媒体标题和销售话术。
2. 把“用户画像”升级为“行为改变”。年龄和身份只是入口，关键是用户原来不做什么，活动后要做什么。
3. 把“流程表”升级为“体验曲线”。活动不是按时间发生，而是在用户心里形成期待、进入、参与、峰值、离场和回访。

## 2. 总流程：大活动全案的十步工作法

| 步骤 | 工作内容 | 输出物 | 不合格信号 |
|---|---|---|---|
| 1. 判局 | 明确委托关系、对象、场域、体量、营销功能 | 活动路由判断表 | 什么活动都套同一模板 |
| 2. 信息采集 | 国内外案例、行业趋势、竞品动作、用户吐槽 | 市场信号表 | 只有正面案例，没有反向信号 |
| 3. 行为改变 | 利益相关方、当前行为、目标行为、阻力、收益 | 行为改变表 | 用户画像停在“25-35岁” |
| 4. 经营模型 | 投入、中间指标、结果指标、长线资产 | 指标传导链 | 目标值没来源、没人采 |
| 5. 叙事主线 | 主叙事、核心冲突、情绪曲线、主场面 | 策略叙事页 | 文案漂亮但与现场无关 |
| 6. 创意机制 | Big Idea、核心玩法、互动规则、传播钩子 | 创意闪卡 | 只换皮，不换机制 |
| 7. 交付系统 | 时间、动线、分工、预算、物料、供应商 | 执行管理包 | 执行团队仍要反复问 |
| 8. 传播承接 | 预热、现场、长尾、渠道、素材、媒体 | 传播矩阵 | 只有海报，没有内容节奏 |
| 9. 风险审查 | 策略、预算、合规、现场、安全、舆情 | Red Team风险表 | 只写“注意安全” |
| 10. 成案终审 | 老板/客户/执行/用户视角模拟 | 上交版Word | 方案无法被3分钟讲清 |

### 1. 执行摘要

本次活动面向[目标人群]，围绕[业务问题/品牌问题/关系问题]展开。当前核心矛盾不是[表面问题]，而是[真实问题]。方案以“[Big Idea]”为核心创意，通过[核心机制1]、[核心机制2]、[核心机制3]形成从触达到参与、从参与到转化/传播/关系沉淀的完整链路。

本活动优先赢得[主判据]，辅助观察[辅助判据1]、[辅助判据2]、[辅助判据3]。活动预算建议为[预算区间]，执行复杂度为[S/M/L/XL]。当前最大不确定性为[关键假设]，需在[时间节点]前通过[验证动作]完成确认。

### 2. 项目背景与核心问题

#### 2.1 为什么现在要做

| 维度 | 判断 | 证据/来源 | 对方案的影响 |
|---|---|---|---|
| 行业趋势 | [行业正在发生什么变化] | [来源或待验证] | [为什么现在是窗口期] |
| 用户需求 | [用户真实痛点/欲望/疲劳点] | [调研/评论/历史数据] | [活动必须解决什么] |
| 竞争环境 | [竞品/同类活动怎么做] | [来源或待验证] | [如何避开同质化] |
| 品牌处境 | [品牌当前优势/短板] | [内部数据/访谈] | [活动承担什么任务] |
| 时机借势 | [节日/热点/政策/节点] | [日历/政策/平台趋势] | [活动为什么有天然话题] |

#### 2.2 核心问题定义

真正要解决的不是“[表面诉求，如办一场热闹活动]”，而是“[真实业务问题，如让目标客户产生购买信任/让渠道愿意推进/让用户愿意二次分享]”。

#### 2.3 不做活动的代价

如果不在当前窗口期行动，可能导致：[流量被竞品截走]、[渠道信心下降]、[销售线索冷却]、[品牌声量被节点淹没]、[内部目标无法达成]。具体保留哪些代价，应依据真实项目选择。

### 5. 活动主题、Big Idea与创意机制

#### 5.1 活动主题

「[活动主题]」  
一句话主张：[一句能被复述的主张]

好主题的判断标准：

| 标准 | 说明 |
|---|---|
| 能复述 | 不是形容词堆砌，别人能转述 |
| 有冲突 | 解决一个清晰矛盾或反常识 |
| 有动作 | 能延展成现场行为，不只是海报文案 |
| 有传播资产 | 能变成照片、视频、标题、话题、用户故事 |
| 有经营贡献 | 能推动主判据，不只是好看 |

#### 5.2 主叙事

本活动讲述的故事是：[主叙事]。

### 6. 活动体验设计

#### 6.1 用户旅程

| 阶段 | 用户接触点 | 用户动作 | 设计动作 | 心理机制 | 成功信号 |
|---|---|---|---|---|---|
| 预热期 | 海报/私域/达人/邀请函 | 看到、好奇、报名 | 悬念、稀缺、明确收益 | 好奇缺口/损失厌恶 | 点击、报名、咨询 |
| 到场前 | 短信/社群/日历提醒 | 确认行程 | 提醒、路线、权益预告 | 承诺一致性 | 到场率提升 |
| 入场 | 签到/领物料 | 领取身份/任务 | 快速识别、分流 | 身份启动 | 排队可控 |
| 参与 | 主玩法/体验区 | 完成任务/互动/交流 | 峰值体验设计 | 参与感/掌控感 | 停留、互动 |
| 高潮 | 发布/抽奖/签约/仪式/共创 | 拍摄、分享、见证 | 主场面与统一口径 | 峰终定律 | 内容产出 |
| 离场 | 礼品/证书/回访问卷 | 带走权益/反馈 | 体面收尾 | 终值记忆 | 满意度 |
| 长尾 | 社群/CRM/内容复盘 | 二次购买/预约/转发 | 回访、报告、素材包 | 再激活 | 转化/复购 |

#### 6.2 峰值时刻

峰值时刻不是“最贵的环节”，而是“最容易被记住和传播的环节”。本活动峰值建议设计为：[主场面]。  
它必须同时满足：现场能发生、用户愿意拍、媒体有标题、老板能复述、预算能支撑。

## 4. 策划者内部思考范围

正式Word给老板/客户看，内部思考范围给策划者用。不要把全部推导塞进上交版。

### 4.1 Brief诊断清单

| 问题 | 要问到什么程度 |
|---|---|
| 谁委托 | 甲方自用、乙方提案、内部协同、招商赞助、政企汇报 |
| 给谁看 | 老板、客户、政府、赞助商、执行团队、用户 |
| 赢什么 | 曝光、拉新、转化、关系、背书、数据、汇报、危机 |
| 面向谁 | To C、To B、To G、To E、B2B2C |
| 在哪里发生 | 线下、线上、混合、新媒体campaign、长周期campaign |
| 体量多大 | S轻量、M标准、L大型、XL战役级 |
| 钱从哪来 | 预算、票务、赞助、销售、资源置换 |
| 谁能拍板 | 决策人、否决人、使用人、执行负责人 |
| 哪些禁区 | 合规、审美、品牌调性、领导偏好、平台规则 |

### 4.3 创意生成范围

用交叉网络生成，不要只靠灵感：

| 品牌/产品锚点 | 可碰撞方向 |
|---|---|
| 产品功能 | 场景化、可视化、挑战化、仪式化 |
| 用户痛点 | 反转吐槽、低门槛解决、身份补偿 |
| 节日节点 | 倒计时、限定、团圆、开学、跨年、年终 |
| 地域文化 | 城市符号、地方生活方式、社区记忆 |
| 平台玩法 | 打卡、挑战、直播、共创、投票、测评 |
| 跨界类比 | 医院、考场、实验室、剧场、市集、运动会 |
| 感官体验 | 味觉、声音、触感、光影、气味、温度 |
| 关系结构 | 用户当主角、老板退后、品牌做服务者 |

每个创意必须过五问：

1. 它改变了谁的什么行为？
2. 它推动哪个主判据？
3. 它现场怎么发生？
4. 它为什么值得被拍、发、讲？
5. 它失败时怎么降级？

| 拉新 | 社群活动、挑战赛、会员日、校招 | 新增用户、留资、CPL | 门槛、权益、表单、私域承接 |
| 促转化 | 促销、直播带货、品鉴会、体验店 | 成交额、转化率、ROI | 货盘、优惠、信任、逼单节奏 |
| 做关系 | 私享会、答谢会、沙龙、酒会 | 到场质量、会后合作、续约 | 邀约理由、圈层、体面、跟进 |
| 要背书 | 峰会、论坛、政企仪式、公益CSR | 嘉宾层级、报道、权威关系 | 规格、议题、仪式、口径 |
| 拿线索 | 展会、招商会、路演、开放日 | MQL、SQL、预约Demo、签约额 | 筛选机制、CRM、会后销售 |

| 修危机 | 道歉会、用户沟通会、媒体澄清会 | 舆论转向、投诉下降 | 事实、补救、克制、证据 |

### 5.2 不同活动怎么适配

| 活动类型 | 必须强化 | 可以弱化 | 最容易翻车 | 关键修法 |
|---|---|---|---|---|
| 发布会 | 新闻点、品类叙事、媒体口径、演示稳定性 | 复杂互动游戏 | 变成领导讲话和参数PPT | 用一个可证明的现场变量展示核心能力 |
| 快闪/市集 | 稀缺感、打卡点、动线、人流安全、社媒资产 | 长篇背景论证 | 只拍照不转化 | 每个打卡点绑定留资、购买或二次触达 |
| 展会/参展 | 截流话术、线索评级、销售承接、展位体验 | 大而全品牌故事 | 扫码领礼污染线索池 | 用诊断、测试、咨询筛出高质量线索 |
| 招商会 | 信任背书、政策刺激、签约机制、逼单节奏 | 过度娱乐化 | 热闹但不签约 | 前置邀约分层，会场内设置签约台和会后跟进 |
| 峰会/论坛 | 议题体系、嘉宾质量、主持串联、媒体通稿 | 低价值互动 | 嘉宾堆砌无观点 | 用一个主议题统领所有session |
| 年会 | 主叙事、员工参与、表彰故事、情绪峰值 | 外部传播 | 像加班或尴尬节目 | 让员工成为故事主体，减少强迫表演 |
| 私享会/品鉴会 | 邀约理由、圈层体面、体验细节、会后关系 | 大规模曝光 | 变免费吃喝 | 控制名单质量，设计一对一跟进 |
| 直播带货 | 货盘、主播信任、节奏、投流、售后 | 复杂现场装置 | 退货率高、ROI亏损 | 提前测品，设置护栏指标和售后预案 |
| 公益/CSR | 真实受益者、透明机制、第三方背书 | 商业转化表达 | 被质疑作秀 | 用可核验数据和长期行动替代口号 |
| 政企仪式 | 规格、礼仪、领导动线、媒体口径、审批 | 过度潮流化 | 规格不匹配或流程失礼 | 先定级别、座次、动线、报批 |
| 校招/雇主品牌 | 人才画像、岗位真实吸引力、投递路径 | 空泛价值观 | 被学生认为画饼 | 用员工真实故事和岗位信息降低不信任 |
| 线上/混合活动 | 平台稳定、互动节奏、备用链路、数据 | 复杂线下动线 | 直播掉线、在线流失 | 15分钟一个互动点，双链路备份 |

## 6. 参考资料与外部信号

公开资料的共同方向很明确：体验营销正在从“办一场活动”变成“创造可参与、可分享、可测量的品牌体验”。国际资料普遍强调个性化、沉浸式体验、第一方数据、活动ROI证明和可持续；国内案例观察则更强调节点借势、社交平台打卡、私域转化、KOL/KOC扩散和即时成交承接。

本模板参考的外部资料类型包括：

| 来源类型 | 参考方向 | 链接 |
|---|---|---|
| Effie | 有效营销奖项强调目标、洞察、策略、执行和结果证据 | https://www.effie.org |
| WARC | 营销有效性、品牌体验、案例库和策略分析 | https://www.warc.com |
| Cannes Lions | 创意奖项中体验、品牌激活和效果类案例的表达逻辑 | https://www.canneslions.com |
| Campaign / AdAge | 国际广告行业案例与品牌活动报道 | https://www.campaignlive.com / https://adage.com |
| Freeman / Bizzabo / EventTrack | 活动营销趋势、参会体验、ROI和数据化运营 | https://www.freeman.com / https://www.bizzabo.com / https://eventmarketer.com/eventtrack |
| SocialBeta / 广告门 / 数英 / 梅花网 / Morketing | 国内品牌活动、快闪、campaign、节日营销和新媒体玩法观察 | https://socialbeta.com / https://www.adquan.com / https://www.digitaling.com / https://www.meihua.info / https://www.morketing.com |

资料使用原则：

1. 国际案例拆“策略结构”和“效果表达”，不要照搬文化语境。
2. 国内案例拆“平台玩法”和“传播节奏”，不要照搬视觉包装。
3. 趋势资料只能证明方向，不能替代本品牌的用户证据。
4. 所有预算、场地报价、法规审批、KOL报价、历史转化率必须针对具体项目重新核实。

## 7. 最终自检

交付前逐条检查：

| 检查项 | 通过标准 |
|---|---|
| 3分钟可讲清 | 能讲清为什么做、怎么赢、花多少钱、风险在哪 |
| 不是旧活动换皮 | 去掉视觉后仍有新的行为机制 |
| 指标可采集 | 每个关键指标都有数据来源和负责人 |
| 创意能落地 | 每个创意都有现场动作、传播钩子、预算支撑 |
| 预算能解释 | 预算不是堆项目，而是支撑体验、传播、转化、风险 |
| 风险有预案 | 高风险项都有A/B方案，不只写“注意” |
| 适配活动类型 | 发布会不像市集，招商会不像年会 |
| 思考与正文分离 | 上交版干净，内部推导可追溯 |

## 8. 一句话使用方式

拿到任何活动需求后，不要立刻写流程。先判定“这是什么局”，再问“要改变谁的什么行为”，然后用“主判据”倒推创意、体验、传播、执行和复盘。这样产出的Word不是模板填空，而是一套能被质疑、能被执行、能被验收的活动方案。
