# 指标传导模型 + 闭环图

供 Step 2 重建目标、Step 5 成型时加载。核心一句话：**判据不是并列的 KPI，是传导的链。只定结果指标、不建传导链，方案就退化成冲转化。**

## 一、四层传导链 × 四维测量

活动效果是「传导」出来的，不是「并列」出来的；指标是「按四维枚举」出来的，不是「拍脑袋列词」出来的。

```
投入层 → 中间指标层 → 结果指标层 → 长线资产层
```

每层指标，按「数量 / 质量 / 效率 / 成本」四维枚举——**只列数量（到场率/GMV）会漏掉体验质量、财务效率、合规成本**：

| 层级 | 数量 | 质量 | 效率 | 成本 |
|---|---|---|---|---|
| 投入层 | 预算 / 内容 / 体验 / 人力 | — | — | 合规成本（报批/安保/保险/法务） |
| 中间指标层 | 到场率 / 传播量 / 互动率 | 决策人比例 / NPS / CSAT / 受众匹配 | 停留时长 / 完播率 / 人均互动 | — |
| 结果指标层 | 转化 / 签约 / GMV / 留资 / 融资信号 | 线索质量（MQL/SQL）/ 签约质量（首付比） | ROI / LTV / 成交周期 | CPL / CAC / 毛利 |
| 长线资产层 | 粉丝数 / 内容量 / 关系数 | opt-in 率 / 心智漏斗 / 画像完善度 | 复购率 / 续约率 / 流失率 | — |

> 四维的价值不只是「列全」，是让归因变精：原来只能写「到场率驱动转化」，现在能写「到场**质量**（决策人比例）+ 体验**质量**（NPS）驱动转化」。质量维度让传导链从粗归因变精确归因。

## 二、五条规则

1. **主判据放在「结果指标层」**，但不能只有结果指标——只有结果指标，就没有传导链。
2. **向上归因**：每个结果指标，必须说清由哪几个中间指标驱动（转化 ← 到场质量 + 体验峰值）。
3. **向下归因**：每个中间指标，必须说清由哪项投入驱动（到场质量 ← 精准邀约 + 嘉宾质量）。
4. **长线资产必须纳入**：活动不是一次性的，是往资产里存东西。只盯当期结果 = 短视。
5. **四维枚举（强制）**：每层指标至少覆盖「数量 + 质量」两维，结果层还必须覆盖「效率 + 成本」。只列数量 = 拍脑袋，会漏掉体验质量和财务效率。

## 三、闭环图产出（强制）

每个方案必须产出一张闭环图：四层节点 + 传导箭头，且**根据用户需求动态生成**——不同动机，链路重心不同：

| 动机 | 链路重心 | 主判据落在哪层 |
|---|---|---|
| 卖货 / 转化 | 结果指标层 | 转化、GMV |
| 品牌 / 占位 | 长线资产层 | 心智、传播、内容沉淀 |
| 关系 / 融资 | 中间指标层 | 到场质量、对接、信任信号 |

- **表达形式**：markdown 里用 mermaid 或 ASCII 箭头图；docx 里转成四层表格 + 箭头。
- **闭环图的另一半是回填**：图不是画完就完事，活动后要把「目标 vs 实际」填回四层链的每一层，看哪层断了。

## 四、回填规则（长闭环）

活动结束后，逐层回填：

```
投入层      实际花了多少 → 花对了吗
中间指标层   实际到场/体验/传播 → 达标了吗
结果指标层   实际转化/签约 → 主判据赢了吗
长线资产层   沉淀了什么 → 心智/关系/数据有没有变厚
```

**断在哪层，下次就补哪层**。例如：结果指标达标、但长线资产没沉淀 → 下次重心往资产层移。这张「断点」就是喂回案例库（`event-types.md`）的关键字段。
