# 四维推导轴（完备覆盖的方法）

供 Step 1 拆维度、Step 3 发散前加载。核心一句话：**清单会漏，推导轴不会。用「七状态 × 两层对象 × 五形态 × 时空」四维，现场推导出任意活动类型。**

> 关键约束：本轴是「查表定位」，不是「多步推理」。AI 拿着需求里的信号词，**一步对表**定位，和查清单一样快。禁止把本轴写成「先判断 A 再判断 B 再判断 C」的推理流——推理流会漂移、会出错。

## 一、活动类型 = 四维的一个组合

```
活动类型 = 七状态目的 × 两层对象 × 五形态 × 时空
```

任何活动，都能落进这四维的某个组合。推导不出来，说明它不属于「活动」，或者轴又漏了（漏了就在对应维度加一个枚举值，不重构）。

## 二、七状态目的轴（查表定位）

| 需求信号（用户原话里的词） | 状态 | 典型活动 |
|---|---|---|
| 「要卖货 / 冲 GMV / 转化 / 促活」 | 行为 | 促销、招商、直播带货、体验店 |
| 「要让人知道 / 记住 / 造声量 / 占心智」 | 认知 | 发布会、媒体会、内容传播、快闪 |
| 「要让人喜欢 / 认同 / 归属 / 留人」 | 情感 | 答谢会、年会、粉丝见面、品牌演绎 |
| 「要拉近关系 / 结盟 / 答谢 / 留客」 | 关系 | 私享会、酒会、政企对接、答谢 |
| 「要钱 / 要渠道 / 要人 / 要数据」 | 资源 | 路演、招商、招聘、数据沉淀 |
| 「要剪彩 / 揭牌 / 签约 / 授牌 / 上市 / 奠基」 | 身份 | 开工仪式、揭牌、签约仪式、授牌 |
| 「要体检 / 运动会 / 培训 / 急救 / 健康」 | 生理能力 | 体检、健康跑、技能培训、急救演练 |

> 七状态 = 认知 / 情感 / 行为 / 关系 / 资源 / **身份** / **生理能力**。最后两个是原「五状态」漏掉的——剪彩揭牌是「确认身份资格」，体检培训是「改变身体能力」，都不属于前五类。

## 三、两层对象轴

| 层 | 含义 | 例子 |
|---|---|---|
| 参与者 | 谁来现场 | 消费者 / 员工 / 媒体 / 领导 / 公众 |
| 受益者 | 谁最终获益 | 多数活动两者重合；公益/环保/CSR 两者分离（受益者是环境/弱势群体） |

**硬规则**：两者分离的活动（公益、环保、CSR），必须分别写清「参与者是谁、受益者是谁」，别混成一谈。

## 四、五形态轴（参与者与活动的关系）

| 形态 | 参与者角色 | 例子 |
|---|---|---|
| 接受 | 被动看/听 | 发布会、演讲、展览 |
| 参与 | 主动做/玩 | 快闪、体验店、游戏化 |
| 仪式 | 完成象征动作 | 剪彩、颁奖、签约 |
| 连接 | 建立人际连接 | 酒会、私享会、答谢 |
| 共创 | 产出内容 | UGC、挑战赛、内容共创 |

## 五、时空轴

线下 / 线上 / 混合 × 单次 / 周期。

- 「线上型」活动（Webinar / 线上发布会 / AMA / 虚拟活动）是「形态+时空」的组合，不是独立目的——它落进「时空轴=线上」+ 对应目的。
- 「周期型」活动（会员日 / 月度社群活动）落进「时空轴=周期」。

## 六、推导路径格式（强制）

每个创意/方案，必须标注一条推导路径，格式：

```
[七状态] → [参与者/受益者] → [形态] → [时空]
例：行为 → 消费者/消费者 → 参与 → 线下/单次
例：身份 → 领导+员工/组织 → 仪式 → 线下/单次（剪彩）
例：资源 → 公众/环境 → 共创 → 混合/周期（公益）
```

这条推导路径是**贯穿全流程的线索**：Step 3 发散时生成，Step 4 对抗时攻击，Step 5 成型时验证，活动后回写修正。它不是一次性的标签。

## 七、用法（查表 + 落地，两步）

1. **查表定位**：拿需求信号词，对「七状态」表定位目的，再补「对象 / 形态 / 时空」。
2. **查案例锚点**：定位完，去 `event-types.md` 查对应类型的「核心要素 / 成功判据 / 翻车点」落地。

**分工**：axes.md 负责「不遗漏」（完备覆盖），event-types.md 负责「会落地」（案例参考）。清单查得到就走清单（快），查不到走推导轴（全），两者并存，不互相取代。
