# 检索路径库（活水地图）

供 Step 3 发散创意前加载。核心一句话：**对的问题，去对的源拿活水**。检索不是漫无目的地搜，是先判断要什么，再路由到对的源。

## 一、先判断要什么（信号路由）

检索前先问一句：这一步要的到底是哪种信息？不同问题，去不同源，别搞反。

| 要什么 | 去什么源 | 别去 |
|---|---|---|
| 案例灵感 | 数英网 / SocialBeta / 广告门 / 新榜 / 品牌官方号 | 新闻稿 |
| 用户真实口碑 | 小红书 / 抖音评论区 / 微博 / 知乎 / B站弹幕 | 官方宣传稿 |
| 热点趋势 | 微博热搜 / 抖音热榜 / 新榜 / 百度指数 | 旧报告 |
| 行业数据 | 蝉妈妈 / QuestMobile / 艾瑞 / 卡思数据 | 自媒体猜测 |

**铁律**：要「口碑、反应、真实想法」，别用搜索引擎搜新闻——新闻稿会夸大、编造、漏掉最真实的用户声音。

## 二、级联优先级（Tier 1 → 2 → 3，永不颠倒）

每个平台，按顺序走，上层不行再降一层：

- **Tier 1 — 平台站内直搜**：最高信号，真实用户的一手声音。先去平台自己的搜索框搜。
- **Tier 2 — 搜索引擎 `site:` 限定**：`活动词 site:xiaohongshu.com` 这种，补站内搜的漏。
- **Tier 3 — 第三方聚合/数据平台**：最后手段，用于规模统计，不用于抓真实口碑。

**颠倒级联 = 失败模式**。别先上聚合平台，先站内直搜。

## 三、中文活动策划的检索路径

### 案例 / 灵感源

- 数英网、SocialBeta、广告门、新榜、卡思数据 —— 营销案例库，搜「品类词 + 活动词」
- 品牌官方账号（公众号 / 微博 / B站）—— 官方活动回顾，看它自己怎么讲

### 用户口碑源（交叉验证，至少 2-3 个平台）

- **小红书**：站内搜「品类 + 活动词」，看真实笔记 + 评论区
- **抖音**：搜话题 / 挑战赛，看评论区 + 完播/点赞数据
- **微博**：搜活动话题，看实时讨论 + 转发链
- **知乎**：搜相关问题，看长回答
- **B站**：搜活动视频，看弹幕 + 评论区

### 热点趋势源

- 微博热搜、抖音热榜、新榜日榜 —— 看当下什么在热、什么在退烧
- **交叉网络启动时先拉热点**：进入 Step 3 发散、准备跑交叉网络时，先从上面热点源拉当前热点，提取热点背后的「情绪」当燃料（借势不蹭，见 `creative-network.md` 三）。

### 行业数据源

- 蝉妈妈（抖音电商）、QuestMobile（移动互联网）、艾瑞 / 卡思数据（行业报告）

### 非消费端垂直源（政企 / 招聘 / 危机 / 仪式 / 线上）

> 上面的源全是「消费端」的。遇到非消费端活动（政企招商、校招、危机公关、开工仪式、线上内容活动），去这些垂直源，别硬套消费端源——政府招商不会发小红书，仪式活动的「口碑」不在抖音评论区。

| 活动类型 | 垂直源 |
|---|---|
| 政企招商 / 政府关系 | 政府官网、招商局网站、产业园公告、地方党媒 |
| 招聘 / 雇主品牌 | 招聘平台（BOSS直聘/脉脉/牛客）、雇主品牌报告、Glassdoor 类点评 |
| 危机公关 / 舆情 | 舆情监测平台、主流媒体评论、监管公告、黑猫投诉 |
| 仪式型（开工/签约/揭牌） | 政府新闻、行业垂直媒体、地方电视台 |
| 线上 / 混合活动 | 各平台线上活动数据、完播率/参会率数据源、B端活动平台 |

**硬规则**：先判断活动是「消费端」还是「非消费端」，再选源。用错源 = 搜不到真信息。

## 四、反模式（踩过的坑，别犯）

1. **用新闻稿/官方宣传代替真实口碑** —— 会夸大、编造，漏掉最真实的声音。
2. **只搜一个平台就下结论** —— 至少 2-3 个平台交叉验证。
3. **报数据不引用原文** —— 数字必须带出处，否则是编的。
4. **过滤负面评价来「平衡」** —— 反向信号（用户讨厌什么）和正向一样重要，有时更重要。
5. **不查一手来源就用二手转载** —— 多个媒体引用同一错误，会造成循环印证假象。

## 五、来源验证（防 AI 编 URL）

AI 会编造「看起来合理但不存在的链接」。每个来源引用前：

1. 抓一下确认链接真实存在（不是 404/403）。
2. 确认内容确实支持你的引用。
3. 抓不到的，诚实标注「待验证」，绝不硬编。

## 六、输出格式（按信号强度分层，不按平台堆）

检索完，按「认同强度」分层输出：

- **Tier S**：多个独立来源都说同一件事 → 强信号，可采信。
- **Tier A**：反复出现，但来源单一 → 中信号，标注存疑。
- **Tier C**：反向信号（用户讨厌/吐槽什么）→ 和正向一样重要。

**必须包含 Tier C。** 用户讨厌什么，往往直接决定创意该避开什么。
