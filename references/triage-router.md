# Step 0 判局分流

任何活动需求先判局，再进入策划。判局不是形式主义，它决定追问方向、创意尺度、实验强度和最终方案结构。

## 一、分流判断表

输出格式：

| 分流项 | 本次判断 | 依据 | 待确认 | 为什么不是其他路由 |
|---|---|---|---|---|
| 委托关系 | 甲方自用 / 乙方提案 / 内部协同 / 招商赞助 / 政企 To G | 用户原话或推断 | 缺失项 | 至少排除 1 个混淆路由 |
| 市场对象 | To C / To B / To G / To E / B2B2C | 目标受众与受益者 | 缺失项 | 至少排除 1 个混淆路由 |
| 活动场域 | 线下 / 线上 / 混合 / 新媒体 campaign / 长周期 campaign | 渠道与触点 | 缺失项 | 至少排除 1 个混淆路由 |
| 活动体量 | S / M / L / XL | 预算、人数、风险、部门数 | 缺失项 | 至少排除 1 个混淆路由 |
| 营销功能 | 认知 / 兴趣 / 转化 / 关系 / 背书 / 数据 / 危机 / 汇报 | 真实动机 | 缺失项 | 至少排除 1 个混淆路由 |
| 交付件 | 一页创意 / 标准方案 / 全案执行 / 招商赞助 / 政企汇报 | 读者与用途 | 缺失项 | 至少排除 1 个混淆路由 |
| 经营复杂度 | 低 / 中 / 高 / 战役级 | 是否涉及报名、票务、赞助、销售线索、供应商、多部门、多城市 | 缺失项 | 至少排除 1 个混淆路由 |
| 叙事强度 | 轻叙事 / 标准叙事 / 强叙事 / 年度叙事 | 是否老板过会、乙方竞标、文旅节庆、政企、品牌年度、发布会、城市事件、高预算 | 缺失项 | 至少排除 1 个混淆路由 |

如果信息不足，先给“临时判断”，但不要把推断写成事实。临时判断只用于分流和提问，不得直接生成完整活动流程、Big Idea 全案、执行排期、预算表、传播矩阵完整方案或 Step 8 上交版方案。

判局结束后必须追加：

| 项目 | 写法 |
|---|---|
| 本次主路由 | 例如：To B 闭门沙龙 + 乙方提案 + M 标准 |
| 本次辅路由 | 例如：需要新媒体预热，但不是 To C 声量活动 |
| 排除路由 | 例如：不按 To C 快闪写，因为主判据是商机推进 |
| 待确认风险 | 例如：预算、邀约名单、决策人比例暂缺 |
| 经营复杂度判断 | 例如：涉及报名、赞助、销售线索，按高经营复杂度处理 |
| 叙事强度判断 | 例如：老板过会 + 年度项目，按年度叙事处理 |

## 二、信息缺口门槛

如果以下任意 3 项以上缺失，Step 0 后必须提问并停止：

- 活动目的或业务问题
- 目标人群
- 委托关系：甲方 / 乙方 / 内部 / 政企 / 招商
- 活动场域：线上 / 线下 / 混合 / 新媒体 campaign
- 时间或周期
- 城市 / 场地 / 平台
- 预算或体量
- 最终用途：内部讨论 / 客户提案 / 老板汇报 / 执行落地 / 竞标
- 成功标准或核心 KPI
- 禁区 / 合规 / 审美风险

缺失 3 项以上时，输出必须停留在：

- 分流判断表
- 本次主路由 / 本次辅路由 / 排除路由
- 关键缺口
- 最多 5 个优先问题
- 下一步建议

缺失少于 3 项时，可以进入 Step 1，但必须显式标注待确认项，后续步骤不得把待确认项写成事实。

硬规则：Step 0 不是填表。写不出“为什么不是其他路由”，就说明判局还没完成。

## 三、委托关系

| 类型 | 判断信号 | 方案重点 |
|---|---|---|
| 甲方自用 | 用户说“给老板/内部/领导看” | 业务问题、预算合理性、ROI、风险、内部资源 |
| 乙方提案 | 用户说“客户/竞标/提案/报价” | 差异化、工作范围、甲方配合、不包含项、验收 |
| 内部协同 | 跨部门、行政、HR、销售、品牌共同执行 | 分工、时间线、资源需求、职责边界 |
| 招商赞助 | 要说服合作方出钱、资源或背书 | 权益包、曝光资源、报价梯度、回报证明 |
| 政企 To G | 政府、园区、协会、国企、公共事务 | 规格、口径、审批、领导动线、媒体通稿、合规 |

## 四、市场对象

| 对象 | 核心问题 | 主判据 |
|---|---|---|
| To C | 用户为什么来、拍、发、买、复购 | 到场、传播、转化、会员资产 |
| To B | 决策人为什么来、是否推进商机 | 决策人比例、MQL/SQL、商机金额、会后推进 |
| To G | 是否符合公共价值、规格和口径 | 到场级别、报道口径、政策资源、项目落地 |
| To E | 员工是否更有共识和归属 | 参与率、满意度、共识度、内部传播 |
| B2B2C | 渠道是否被动员、终端是否能承接 | 订货额、渠道活跃、终端转化、代理商信心 |

## 五、活动场域

| 场域 | 必须补充 |
|---|---|
| 线下 | 场地、动线、安全、物料、人员、审批、天气 |
| 线上 | 平台、观看路径、互动、留资、转化、备用链路 |
| 混合 | 线下体验、线上传播、数据回收、双端互动 |
| 新媒体 campaign | 平台矩阵、内容节奏、达人/UGC、AB 预检 |
| 长周期 campaign | 主活动节点、前后内容资产、阶段目标和复盘 |

## 六、体量分级

| 级别 | 判断标准 | 最终交付候选 |
|---|---|---|
| S 轻量 | 小预算、小人群、低风险、少供应商 | Step 8 可压缩为一页创意 + 简版执行表 |
| M 标准 | 外部受众、明确业务目标、有预算压力 | Step 8 可输出标准文字方案 |
| L 大型 | 多部门、多供应商、多环节、有合规风险 | Step 8 可输出全案执行版 |
| XL 战役级 | 多城市、多平台、多利益方、长周期 | Step 8 可输出 campaign 总案 + 子活动矩阵 |

预算不是唯一标准。低预算但高合规风险，不能按 S 轻量处理。
体量只决定 Step 8 的最终交付颗粒度，不授权跳过 Step 1-7。

## 七、营销功能

| 功能 | 设计重心 |
|---|---|
| 认知 | 话题、媒体、内容资产、搜索占位 |
| 兴趣 | 体验、故事、达人、用户证言 |
| 转化 | 权益、限时、成交话术、CTA |
| 关系 | 圈层、私享、对接、会后跟进 |
| 背书 | 嘉宾、机构、媒体、政府、案例 |
| 数据 | 报名、标签、互动、问卷、CRM 回填 |
| 危机 | 事实、态度、补救、舆情监测 |
| 汇报 | 逻辑、指标、预算、风险、亮点包装 |

## 八、交付件路由

| 交付件 | 读者 | 适用 |
|---|---|---|
| 一页创意提案 | 老板/客户先看方向 | 早期沟通、S 轻量 |
| 标准文字方案 | 市场部/项目负责人/客户 | M 标准 |
| 全案执行版 | 执行团队/供应商/跨部门 | L/XL、大型落地 |
| 招商赞助版 | 赞助商/合作方/竞标客户 | 要钱、要资源、要权益 |
| 政企汇报版 | 政府/国企/协会/园区/领导 | To G、公共事务、仪式类 |

硬规则：判局后必须说明“为什么不是另一个路由”。例如“这是 To B 闭门会，不按 To C 快闪写，因为主判据是决策人比例和商机推进，不是社媒声量”。每个关键判断至少排除 1 个容易混淆的路由，防止分流表变成装饰。

## 九、经营复杂度

| 级别 | 判断标准 | 后续影响 |
|---|---|---|
| 低 | 内部小活动、少供应商、无报名/赞助/销售承接 | Step 6 只输出最小可执行版本 |
| 中 | 有外部受众、预算压力、基础报名/传播 | 加载报名、预算、数据采集的轻量表 |
| 高 | 涉及赞助、票务、销售线索、多供应商、多部门 | 强制加载交付系统模块 |
| 战役级 | 多城市、多平台、多利益方、长周期、高预算 | 强制关键路径、RACI、赞助/数据/传播接口 |

## 十、叙事强度

| 级别 | 判断标准 | 后续影响 |
|---|---|---|
| 轻叙事 | 小型内部/执行导向活动 | 只需主题和情绪收束 |
| 标准叙事 | 常规对外活动、标准方案 | 输出主叙事、核心冲突、情绪曲线 |
| 强叙事 | 老板过会、乙方竞标、发布会、政企、文旅 | 强制加载 `china-market-narrative.md` |
| 年度叙事 | 城市事件、品牌年度项目、文旅节庆、高预算项目 | 强制年度级记忆点、主场面和媒体/领导话术 |
