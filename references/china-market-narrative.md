# 中国市场叙事主线

本文件用于 Step 4 叙事主线、Step 8 成案、Step 9 叙事终审。它解决中国市场活动方案常见问题：合理但没故事、完整但没势能、执行很满但老板记不住。

## 一、触发条件

命中任一项必须加载：

- 老板过会、乙方竞标、正式提案、高预算。
- 文旅节庆、城市事件、政企活动、园区/协会/国企项目。
- 品牌年度项目、发布会、周年庆、峰会论坛。
- 用户明确要求故事性、传播性、仪式感、主线、主题、调性、领导讲话、媒体口径。

文旅、艺术文化、海边社区、阿那亚类项目若需要加载强叙事示例，必须先按 `culture-tourism-boundary.md` 确认命中，再加载 `culture-tourism-strong-narrative.md`。普通年会、发布会、招商会、宠物活动或内部活动只使用本文件的通用叙事方法，不套文旅强叙事气质。

## 二、叙事六件套

| 叙事组件 | 要求 |
|---|---|
| 主叙事 | 一句话讲清这场活动到底在讲什么故事 |
| 核心冲突 | 过去 vs 现在、用户痛点 vs 新答案、城市旧印象 vs 新形象、品牌困境 vs 破局 |
| 情绪递进 | 从期待、进入、参与、峰值、收束到余韵 |
| 主场面 | 老板/客户/媒体能复述的年度级画面 |
| 金句表达 | 不是空口号，而是能放在首页、发布稿、领导讲话里的主张 |
| 中国语境适配 | 面子、秩序、仪式、关系、身份、城市/品牌站位、领导可读性 |

## 二点五、从摘要到完整内容

六件套是叙事索引，不是叙事正文。强叙事、文化节庆或用户要求完整故事/概念案时，加载 `narrative-and-concept-delivery.md`，补完整母叙事、主要内容单元和前后衔接；先讲得清一场体验，再压缩成主张。主场面不能替代全场内容，表格字段齐全不代表故事成立。

所有活动都要让读者明白内容为什么这样组织；只有命中条件才另交概念案。先依据真实任务选择连接方式，允许以一种为主、另一种为辅，不为凑类型全部采用：

| 连接方式 | 适用任务与内容推进 | 不能替代它的表面形式 |
|---|---|---|
| 论证 | 发布、论坛、推介：提出具体问题 → 展示证据/演示 → 回应疑问与限制 → 支持一个判断或决策 | 产品形容词、议题名、嘉宾名录 |
| 体验 | 展览、试用、工作坊：建立感知/规则 → 体验可察觉的变化 → 得到理解、能力或作品 | 只有打卡点、分区名、任务数 |
| 关系 | 答谢、内部、私享：识别共同处境 → 看见具体贡献/需求 → 建立有依据的认可或连接 → 约定后续 | 强迫破冰、虚构用户感动、统一扫码 |
| 时间 | 周年、成果回顾、长期项目：关键事实及其变化 → 转折的原因 → 现在的状态与下一步 | 按年份堆照片、把复演包装成新篇章 |
| 空间 | 游园、场地展陈、多点节庆：入口理解 → 各点独立发现 → 路径/对照关系 → 可选择的收束 | 地图箭头、同一视觉、强制集章 |
| 剧情 | 戏剧、叙事演出：人物处境与欲望 → 行动与阻力 → 选择造成的转折 → 结果与余韵 | 诗意命名、朗诵主题、只写高潮场面 |

这是一种内容组织选择，不新增步骤或审批。每个主要单元在已选创意深化和成案时，沿用 `narrative-and-concept-delivery.md` 的内容说明要求；一般会议可用论证顺序，普通年会可用真实贡献与共同成果，不编造戏剧情节。主叙事中承诺的理解、体验或行动，必须由具体单元承接，不能全部留给主持人总结。

## 三、主叙事公式

主叙事不是主题名。用以下公式推导：

```
过去人们以为____，但现在真正的问题是____。
这场活动要让____看见/参与/相信____。
本次通过____内容与____动作，使参与者获得____。
```

示例格式：

- 发布会写法：`通过真实使用任务的演示与问答，让目标用户判断产品在哪些条件下能解决其问题、有哪些限制。`
- 节庆写法：`围绕已核实的地方生活材料，组织相互对照的作品与观看路径，让首次观众读懂一个完整主题。`
- 答谢会写法：`通过具体合作成果回顾和有需求依据的引荐，让客户看见共同贡献并找到下一次合作的对象。`

以上仅示范句式。正式项目必须替换成真实问题、素材和内容，不能把句式本身当作 Big Idea。

## 四、核心冲突

核心冲突是活动需要回答的真实张力，可以是问题与证据、不同观点、体验预期与发现、关系诉求或剧情阻力；不要求制造敌人或人际对抗。常见冲突：

| 冲突类型 | 用法 |
|---|---|
| 旧印象 vs 新答案 | 城市、品牌、行业焕新 |
| 热闹 vs 有用 | 年会、峰会、招商会反模板 |
| 大众声量 vs 圈层身份 | 高端私享、会员活动 |
| 官方表达 vs 用户参与 | 政企、文旅、城市活动 |
| 产品功能 vs 生活意义 | 发布会、品牌活动 |
| 一次活动 vs 长期资产 | 年度项目、campaign |

## 五、情绪曲线

内部必须完成情绪递进，用来校验主叙事是否能落到现场动作。干净方案只展示对拍板有用的情绪主线、主场面或关键体验节点；情绪分析表默认进入思考过程文件，但让读者理解“看见什么、为何转折、如何结束”的体验正文必须保留在方案或概念案中。

| 阶段 | 用户情绪 | 设计动作 | 输出资产 |
|---|---|---|---|
| 预热 | 好奇/期待 | 悬念、邀请、预告 | 海报、预热视频 |
| 进入 | 被重视/进入角色 | 签到、身份物、动线 | 打卡图、身份凭证 |
| 参与 | 好玩/有用/被看见 | 互动、共创、体验 | UGC、数据、线索 |
| 峰值 | 惊喜/荣耀/共鸣 | 主场面、仪式、揭晓 | 短视频、媒体图 |
| 收束 | 体面/余韵/行动 | 礼物、承诺、会后 CTA | 回访、CRM、复盘 |

表中情绪与动作是可选示例，不能预先宣布用户一定惊喜、共鸣或感动。观看、安静思考和自行参观都可构成有效体验；“参与”不等于上台、扫码或共创。专业会议可以从不确定到能判断，纪念活动可以保持庄重，闭门交流可以没有公开传播高潮。对每个保留节点，写清具体内容怎样造成预期变化，以及前一段留下什么问题/成果由下一段接住；若为并列结构，应直接说明并列关系。

## 六、领导/客户可读性

给决策者看的表达要能上会：

| 场景 | 表达重点 |
|---|---|
| 老板 | 一句话问题定义、主场面、预算价值、风险可控 |
| 甲方客户 | 真实动机、差异化、可执行、可汇报 |
| 政府/国企 | 站位、秩序、公共价值、媒体口径、合规 |
| 赞助商 | 目标人群、权益履约、数据证明、续约空间 |
| 执行团队 | 主线、动作、分工、边界、降级 |

## 七、社媒传播话术

同一个活动要给不同平台准备不同说法：

| 渠道 | 话术重点 |
|---|---|
| 媒体/通稿 | 站位、事实、主办方价值、行业意义 |
| 小红书 | 场景、体验、审美、可拍可感 |
| 抖音/视频号 | 主场面、情绪峰值、反差、人物 |
| 朋友圈 | 身份、关系、我来过、我参与了 |
| 领导汇报 | 问题定义、成果数据、风险控制、下一步 |

渠道按目标和公开边界选择。对外发布的实际标题、导语、邀请或短视频正文必须来自已展开的活动内容；不得把拟案写成已发生的成果，把预设观点写成嘉宾原话。闭门、内部或禁拍活动可将传播对象限制为获授权的特定读者，用脱敏结论、纪要或后续交流承接。

## 八、叙事终审

Step 9 必须问：

1. 老板听完 30 秒能不能复述？
2. 对本次确有的媒体/内部读者，是否有依据充分、可准确转述的核心内容？
3. 用户有没有可带走、可复述或在允许范围内分享的收获？
4. 主场面或关键内容在本次场域中提供了什么不可被一句口号替代的价值？
5. 去掉辞藻后，是否还有真实动作支撑？

任一失败，判为“叙事可读性不足”，必须回到 Step 4 或 Step 5 修正。

不适用的公开传播、拍摄或现场要求，须按已确认目标说明替代判据；不得为通过终审新增用户不需要的媒体传播、互动或线下环节。未涉及主叙事与创意方向的局部解释缺失，在原单元内补全，不重复开启已确认决策。

强叙事或概念案同时通过 `narrative-and-concept-delivery.md` 的内容完整性检查。只满足一句话和一张主场面图，不能判叙事通过。
