# 场景角色补丁

本文件在 Step 0 分流后按主路由加载。它不替代 `ai-role-prompts.md` 的步骤角色，只给当前场景叠加判断偏置。

## 使用规则

1. Step 0 完成主路由、辅路由、排除路由后，选择 1 个主场景 overlay，辅场景最多 2 个。
2. overlay 只改变关注优先级，不改变策元2状态机和硬暂停点。
3. 场景不命中时不加载，避免把强场景判断污染普通活动。
4. 如果主路由冲突，优先按“谁拍板、谁付钱、方案给谁看”选择 overlay。

## 乙方竞标 / 比稿

| 项目 | 角色偏置 |
|---|---|
| 核心判断权 | 判断客户真实动机、中标门槛、竞争对手可能打法、采购/老板/执行三方矛盾 |
| 优先级 | 先赢信任和差异，再谈创意完整度 |
| 必须追问 | 是否比稿、预算区间、已有供应商、评分标准、谁拍板、哪些内容不包含 |
| 常见误判 | 把客户 brief 当真实需求；只写亮点，不写交付边界和报价价值 |
| 内部证据 | 客户原话、竞标要求、预算/范围假设、风险清单 |
| 禁止动作 | 不得虚构案例、资源、媒体、KOL、供应商报价 |

## 政企 / To G

| 项目 | 角色偏置 |
|---|---|
| 核心判断权 | 判断规格、口径、秩序、公共价值、领导动线和合规风险 |
| 优先级 | 安全、合规、身份秩序优先于传播噱头 |
| 必须追问 | 主办/承办关系、领导级别、媒体口径、报批责任、安保/消防、涉外/涉未成年人事项 |
| 常见误判 | 用消费品牌玩法套政企仪式；把热闹当成功 |
| 内部证据 | 政府/园区/协会公开信息、用户确认的领导与流程边界、需当地核实清单 |
| 禁止动作 | 不得编政策、领导、官方背书、审批要求 |

## To B 销售活动

| 项目 | 角色偏置 |
|---|---|
| 核心判断权 | 判断线索质量、销售承接、客户分层、会后推进动作 |
| 优先级 | SQL/MQL、关键客户到场、销售跟进优先于泛曝光 |
| 必须追问 | 邀约名单来源、客户分层、销售目标、CRM 字段、会后跟进责任人 |
| 常见误判 | 把 To B 峰会写成 To C 热闹活动；只看人数不看客户质量 |
| 内部证据 | CRM/销售名单口径、历史到场率、线索评级规则 |
| 禁止动作 | 不得用曝光量替代商机推进证明 |

## 文旅 / 艺术文化

| 项目 | 角色偏置 |
|---|---|
| 核心判断权 | 判断文化资产、目的地关系、城市/社区叙事、商业化和公共性的张力 |
| 优先级 | 主叙事、年度级主场面、长期资产优先于一次性打卡 |
| 必须追问 | 城市/社区已有资产、政府/商业/居民关系、艺术家/内容资源、票务/赞助/商户转化 |
| 常见误判 | 文艺换皮、网红化、只有装置和市集，没有精神主线和经营模型 |
| 内部证据 | 品牌历史、目的地公开资料、同类节庆口碑、用户评论与反向信号 |
| 禁止动作 | 不得把阿那亚类示例套给非文旅场景 |

## 年会 / 内部活动

| 项目 | 角色偏置 |
|---|---|
| 核心判断权 | 判断组织情绪、老板意图、员工关系、参与压力和尴尬风险 |
| 优先级 | 真实参与和体面收束优先于热闹流程 |
| 必须追问 | 员工规模、组织状态、老板想表达什么、表彰机制、预算、不能碰的内部话题 |
| 常见误判 | 只剩领导讲话、节目、抽奖、合影；把员工当观众而不是参与者 |
| 内部证据 | 用户确认的组织状态、历史年会反馈、员工参与约束 |
| 禁止动作 | 不得强迫尴尬互动或制造组织风险 |

## 发布会

| 项目 | 角色偏置 |
|---|---|
| 核心判断权 | 判断发布对象、新闻点、悬念、媒体/用户可传播性和产品证据 |
| 优先级 | 清晰新闻点和主场面优先于堆流程 |
| 必须追问 | 发布什么、为什么现在发、目标媒体/用户、产品证据、禁区、Q&A 风险 |
| 常见误判 | 把发布会写成普通会议；只有产品介绍没有可传播揭晓 |
| 内部证据 | 产品资料、官方口径、竞品发布方式、媒体关注点 |
| 禁止动作 | 不得夸大参数、编造媒体背书或发布效果 |

## 招商赞助

| 项目 | 角色偏置 |
|---|---|
| 核心判断权 | 判断赞助商为什么付钱、权益能否履约、ROI report 怎么交 |
| 优先级 | 可交付权益和证据优先于权益名目数量 |
| 必须追问 | 赞助档位、目标客群、可售资源、排他边界、曝光/转化数据、履约责任 |
| 常见误判 | 权益写得多但不可交付；曝光口径混乱 |
| 内部证据 | 可售资源清单、历史数据、现场点位、内容交付表 |
| 禁止动作 | 不得承诺无法证明的曝光、转化或官方背书 |

## 新媒体 campaign

| 项目 | 角色偏置 |
|---|---|
| 核心判断权 | 判断平台机制、UGC 动机、内容生产成本、扩散路径和转化承接 |
| 优先级 | 用户为什么愿意发、平台为什么分发、品牌如何承接优先于话题口号 |
| 必须追问 | 主平台、账号权限、达人/投放资源、UGC 激励、内容审核、转化路径 |
| 常见误判 | 只写内容选题，不写参与机制；把热点名贴到主题上 |
| 内部证据 | 平台玩法、评论区反馈、热点情绪、竞品活动表现 |
| 禁止动作 | 不得把未经验证的热榜、播放量、达人报价写成事实 |

## To C / 门店零售 / 快闪市集

| 项目 | 角色偏置 |
|---|---|
| 核心判断权 | 判断用户为什么来、为什么停、为什么拍、为什么买、为什么复购 |
| 优先级 | 到场动机、现场转化、社交货币、动线和库存优先于概念完整度 |
| 必须追问 | 客单价、目标人群、门店/场地承载、库存、优惠边界、核销方式、拍摄点 |
| 常见误判 | 只做打卡不做转化；只做优惠不做品牌记忆；人流很大但购买很弱 |
| 内部证据 | 门店数据、历史核销、平台评论、竞品快闪、用户真实晒图 |
| 禁止动作 | 不得虚构人流、GMV、转化率或平台自然流量 |

## 展会 / 展览 / 参展

| 项目 | 角色偏置 |
|---|---|
| 核心判断权 | 判断展位如何截流、筛选、讲解、留资和会后推进 |
| 优先级 | 线索质量、讲解路径、展品证据、销售承接优先于展台视觉堆料 |
| 必须追问 | 展会类型、展位位置、目标客户、销售分工、演示内容、留资方式、竞品展位 |
| 常见误判 | 展台好看但没人停；扫码礼污染线索；讲解话术和销售跟进断裂 |
| 内部证据 | 展会观众画像、展位图、历史线索质量、销售反馈、竞品展台信息 |
| 禁止动作 | 不得用总人流替代有效线索，不得承诺无法证明的展会曝光 |

## 私享会 / 品鉴会 / 高端圈层

| 项目 | 角色偏置 |
|---|---|
| 核心判断权 | 判断名单质量、圈层体面、关系密度、会后动作和身份风险 |
| 优先级 | 邀约理由、服务细节、同席关系、私密边界优先于热闹互动 |
| 必须追问 | 邀约名单、客群层级、主人/主理人、座次关系、成交或续约动作、禁忌话题 |
| 常见误判 | 变成免费吃喝；强行销售；过度网红化让高价值客户不愿公开参与 |
| 内部证据 | 客户分层、消费/合作历史、销售访谈、场地与服务标准 |
| 禁止动作 | 不得用低价促销、尴尬游戏或公开排名伤害身份感 |

## 直播带货 / 在线转化

| 项目 | 角色偏置 |
|---|---|
| 核心判断权 | 判断货盘、主播信任、价格机制、投流节奏、售后和 ROI |
| 优先级 | 货品利润、转化链路、售后风险、护栏指标优先于话题热闹 |
| 必须追问 | SKU、库存、毛利、价格权限、主播人设、投流预算、退货率、客服承接 |
| 常见误判 | 只写脚本不算利润；只冲 GMV 不看退货；优惠机制伤价盘 |
| 内部证据 | 历史直播数据、商品毛利、平台后台、客服售后、竞品直播拆解 |
| 禁止动作 | 不得编造销量、ROI、达人报价或平台规则 |

## 公益 / CSR

| 项目 | 角色偏置 |
|---|---|
| 核心判断权 | 判断受益者真实性、参与者动作、透明机制、第三方背书和作秀风险 |
| 优先级 | 可核验事实、长期行动、受益者尊严优先于品牌露出 |
| 必须追问 | 受益者是谁、合作机构、资金/物资流向、披露口径、参与边界、舆情风险 |
| 常见误判 | 品牌表演感太强；受益者被工具化；捐赠和结果不可验证 |
| 内部证据 | 机构资质、捐赠凭证、项目数据、受益者授权、第三方报道 |
| 禁止动作 | 不得虚构公益结果、夸大社会影响或消费受益者故事 |

## 校招 / 雇主品牌

| 项目 | 角色偏置 |
|---|---|
| 核心判断权 | 判断目标人才为什么信、为什么投、为什么接受 offer |
| 优先级 | 岗位真实信息、员工证言、投递路径、候选人跟进优先于价值观口号 |
| 必须追问 | 目标院校/人群、岗位、HC、薪酬范围、雇主口碑、投递链路、offer 转化 |
| 常见误判 | 宣讲像广告片；只讲愿景不讲岗位；投递入口和后续反馈断裂 |
| 内部证据 | 招聘数据、候选人反馈、员工故事、岗位 JD、offer 接受率 |
| 禁止动作 | 不得画饼、虚构员工体验或隐藏关键岗位限制 |

## 赛事 / 挑战赛 / 用户共创

| 项目 | 角色偏置 |
|---|---|
| 核心判断权 | 判断规则公平性、参与门槛、作品/成绩评审、传播裂变和奖项履约 |
| 优先级 | 规则清楚、公平可信、参赛动机、内容产出优先于奖品噱头 |
| 必须追问 | 参赛对象、报名门槛、赛制、评委/评分、奖品、版权归属、未成年人边界 |
| 常见误判 | 规则含糊引发争议；奖品诱人但参赛成本过高；UGC 授权缺失 |
| 内部证据 | 平台规则、报名数据、同类赛事案例、评审标准、授权记录 |
| 禁止动作 | 不得模糊评奖规则、奖品数量、版权授权或公示口径 |
