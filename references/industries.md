# 行业要点（示例快速通道，非穷举）

本表是「常见行业示例 + 快速通道」，**不是穷举清单**——行业是无限、长尾、会过时的（宠物、电竞、婚庆、殡葬、滑雪……）。表里有的直接查（快），表里没有的走下方「行业判断 + 动态搜索」方法（全）。

供 Step 2 行为改变、Step 5 创意机制、Step 6 交付系统按行业校准方案。五件套：**调性**（受众要什么感觉）、**雷区**（碰了就死）、**预算结构**（钱主要花哪）、**合规红线**（法律风险）、**标准模块**（这个行业办活动的标配清单骨架，是「具体清单层」的默认条目，查表取用、别强制枚举）。按需取用，不全背。

**适用解释优先于表内速记**：调性和预算排序是待检验的常见候选，不是行业定律；人群偏好必须来自本次任务、参与情境和证据，不能由年龄、性别、收入或行业标签直接推出。表内“雷区”含品牌风险与法定限制两类，前者按本次 brief 验证，后者按适用地区、产品类别、活动行为及最新权威来源核实。“合规红线”只是核验索引，不代表每场活动必然适用，也不代表已列全；不据此编造资质、许可、报批门槛、年龄线、比例或金额。预算中的 `>` 表示优先检查的成本驱动，不构成报价或固定分配比例。

只加载与本次活动实际发生内容有关的行业要求。客户所属行业、活动涉及行业、参与者职业可以不同；企业内部表彰未涉及产品推广时，不强塞行业销售模块。复合项目逐单元标明行业适用范围和共有接口，例如艺术演出使用作品/版权要求，食品市集使用餐饮核验要求，赞助展示使用权益要求，不能互相代替。知识不足时定位缺口，完成有依据的拟案部分；没有专业核实不等于已经合规。

## 行业判断 + 动态搜索（表里没有的行业走这里）

行业是无限、长尾、会过时的，硬编码清单补不完。表里没有的行业，按这套**动态判断 + 搜索**，现场生成五件套：

1. **提取行业信号**：从用户输入里抓「行业/领域」词（宠物、电竞、婚庆、殡葬、滑雪……）。
2. **归类到大类**：判断它属于消费 / 工业 / 文化 / 健康 / 专业服务……大类决定调性倾向（消费=热闹实惠，文化=圈层沉浸，健康=专业可信）。
3. **动态生成搜索提示词**：`[行业词] + 活动策划 + 调性 / 雷区 / 预算结构 / 合规红线 / 标准模块`，逐项去搜（检索路径见 `search-paths.md`，访问、登录、权限和降级见 `source-access-and-login-workflow.md`）。
4. **用横纵分析落地**：搜到的信息，走「拆解 + 对标」（`creative-inputs.md` 三）落成五件套，补进本表作为新的示例。

四个动作的适用细则：提取信号时同时识别具体服务对象和本次行为；归大类只用于选择检索方向，上面的调性括注不能直接作为用户洞察；搜索优先寻找产品/服务资料、真实用户问题、专业内容样本和适用规则，再查活动案例。所谓“补进本表”，本次运行先补入项目过程记录中的同结构五件套，稳定方法论仍按下方第 5 条沉淀审核，不直接改写本文件。

未知行业的项目卡沿用五件套，并补 `本次专业问题 | 采用的内容模块及其有效规格 | 确认依据 | 未知项对方案影响`。至少有一条能够使内容真正区别于相邻行业的依据，例如展示物、业务决策、体验方法、专业术语解释或受约束的现场动作；只有行业名、形容词和配色不同，判为适配未完成。不熟悉的专业术语保留可核实原称，不擅自扩写其效果。

检索规则与事实逐项绑定，优先主管机构、现行官方规则、产品/场地方和有权限的专业方资料；记录发布/生效日期、适用地区和版本。营销案例只能提供表达/机制线索，不能充当法规、认证或技术参数的依据。查不到时说明未知的是哪一条件、影响哪一模块、由谁/何种资料可确认；不编一个“行业通用标准”填空。

> 关键：行业是「动态判断 + 搜索」出来的，不是「硬编码」出来的。硬编码的行业只是「常见示例」，是快速通道，不是兜底。别因为表里没有就卡住，也别为了「补全」而无限往表里加行业。

## 使用规则

1. **先对行业，再对活动类型**。同一场「发布会」，汽车和美妆的调性、预算、合规完全不同。表里查不到这个行业 → 走上方「行业判断 + 动态搜索」，别硬套最相近的行业。
2. **雷区即禁区**。方案里出现雷区词汇/动作，直接回炉。
3. **合规红线在 Step 6 交付系统和 Step 7 对抗审查强制查**。不熟悉的行业，联网核实最新法规；查不到、需登录、需权限或地区规则不明时，标“待验证/需当地核实”，别凭印象写。
4. **标准模块 = 具体清单层的默认条目**。进入环节设计时（Step 6），查本表「标准模块」列，作为「这个行业要列哪些清单」的骨架，再配合横纵分析的「细化」动作（`creative-inputs.md` 三）落到「需要哪些内容、细到什么程度」。这是查表取用，不是强制枚举——用户勾选需要的模块即可。
5. **新增行业样本先沉淀，不直接改表**。动态搜索得到的长尾行业经验，先写入 `output/case-library/` 或 `output/improvement-log/`；经人工审核后再升级为本文件方法论。

上述使用规则不把形容词判定成硬禁区，也不把标准模块全量强塞给用户。“雷区”应检查实际动作及其后果；术语如“逼定”“稀缺”“背书”不能成为虚构限量、收益、权威或迫使参与的理由。选择模块与细化属于既有策划职责，可依据 brief 和目标提出适用判断，不要求用户逐项替策划完成行业设计。

交付前做一次换行业检验：隐藏行业名后，能否从具体内容、证据、体验和约束看出这是本次项目？若只剩通用签到—讲话—互动—转化，需要回到相关步骤深化。检验内容实质，不为了显得专业堆术语、篇幅或新增文件；S 轻量只保留本次关键模块和实际影响决策的核验事项。
