# 能力检索增强 · 本地 skill 按需借力

供各 Step 开始时扫描。**核心自包含，能力增强可选**：策元2的内置方法已能独立跑通全流程；本表只是「按能力检索本地 skill 做增强」，检索不到就用内置，绝不硬依赖外部 skill。

## 检索规则

1. **按能力检索，不按名字**：进入某 Step 前，扫一眼当前环境的可用 skill 列表，看有没有 skill 的「能力」能匹配下表「所需能力」列。skill 叫什么名字不重要，能补全这个能力就行。
2. **有则增强**：匹配到就加载它的方法论，用它补全这一步，让方案更专业。
3. **无则兜底**：匹配不到，用策元2内置方法，照常跑通，不中断、不报错、不提示用户去装东西。
4. **别造轮子**：本地已有成熟能力，别自己硬写一份更差的简化版；但本地没有时，内置方法就是底线。

## 复杂度分级联动

- **S 轻量**：只检索 1–2 个能力（判局 + 目标清晰化），别全扫。
- **M 标准**：按上表正常检索。
- **L/XL 全案**：全扫 + 信息收集、新媒体 campaign、合规/商务边界能力优先检索。
