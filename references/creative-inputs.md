# 创意输入 · 动机 + 交叉网络 + 市场信息碰撞 + 横纵分析 + 心理机制

供 Step 1 拆解、Step 3 发散、Step 5 环节设计时加载。只给方法，不给废话。

## 一、5 Whys 动机拆解

**追问规则**：从「表面需求」往下挖，顺着每次回答继续追问，挖到「钱、权、关系、怕」四词之一就停——**不强制凑满 5 次**。每次追问必须基于上一次的回答，不是机械重复「为什么」。

**动机类型清单**（判断归属，别硬套）：

- 募资 / 融资信号：给投资人看信心
- 渠道压货：给经销商看决心，逼订货
- 向上汇报 / 政绩：给老板或上级看成果
- 留人 / 凝聚力：稳军心，防离职
- 卖货 / 转化：直接冲销售
- 品牌占位：抢心智，压竞品
- 危机公关：灭火，挽回声誉

**判据**：同一句「办发布会」，动机是「募资」还是「卖货」，方案是两种物种。挖不到动机，就停下来问，别硬往下走。

## 二、交叉网络（Step 3 发散的总引擎）

核心一句话：**创意 = 锚点 × 可变域 → 反直觉组合。** 交叉网络是发散的**乘法引擎**——把「线性组装 N 个方向」升级成「碰撞出 N×M 个组合」。

> **统领关系（关键）**：交叉网络是 Step 3 发散的顶层框架，下面的**横纵分析（三）、心理机制推理卡（六）、跨界移植（八）、市场信息碰撞（九）不是并列的四个动作，而是交叉网络的输入**——横纵分析产素材（喂 H 热点域 / C 文化域）、推理卡产情绪（喂 E 情绪域）、跨界移植产机制（喂 X 跨界域）、市场信息碰撞产「当下有效玩法 / 审美疲劳 / 竞品空白 / 用户反向信号」。发散时先跑交叉网络，缺哪个域的输入，再回头调对应方法。交叉网络负责把它们**乘**起来，不负责评判（评判交给 Step 4）。

### 锚点域（1 个，不变）

活动的「核心元素」——这场活动/品牌「我是谁」：

| 活动类型 | 锚点（示例，动态判断，不硬套） |
|---|---|
| 发布会 | 悬念（One more thing） |
| 快闪 / 市集 | 稀缺 |
| 答谢会 / 私享会 | 专属 |
| 招商会 | 信任 |
| 年会 / 团建 | 归属 |

**用法**：发散前先问「这场活动的锚点是什么」——锚点不锁定，交叉就是乱撞。

### 可变域（6 个，动态生成，不硬编码穷举）

| 域 | 关键词 | 值怎么来 |
|---|---|---|
| H 热点 | 及时性 | 实时拉当前热点，提取热点背后的「情绪」 |
| C 文化 | 共鸣 | 圈层暗号、时代记忆、集体情绪、亚文化 |
| E 情绪 | 底层 | 受众此刻的焦虑/好奇/炫耀/归属/怕落单（喂推理卡，见六） |
| X 跨界 | 借机制 | 不相干行业解决同一动机的机制（喂跨界移植，见八） |
| S 感官 | 五感 | 视觉/听觉/嗅觉/触觉/味觉的具体动作 |
| T 冲突 | 张力 | 反常识、反转、悖论、禁忌、留白 |

**克制原则**：起步用「锚点 + 3 个核心域（热点 / 情绪 / 跨界）」，其余域按需加。域越多越失控，宁精勿滥。

### 交叉算子（3 种）

1. **嫁接**（杜蕾斯法）：把外部要素「焊」到锚点上——拉伸、弯曲、组合、替换。
2. **双域碰撞**：锚点 × 任一变域，找反直觉交集。
3. **三域撞击**：锚点 × 两个变域，撞出「只有这个组合才有」的创意。

### 产出规则（守「发散收敛分离」）

- 每次交叉只产出「**一句核心概念 + 一句 self-steelman（为什么有意思）**」，**不做任何评判**。
- **反直觉优先**：不反直觉 = 平庸，弃。合理性交给 Step 4 对抗审查。
- **动机做第一道筛**：交叉产生的候选，先用 Step 2 的主判据粗筛，动机不对的不进发散列表。
- **时空轴自检**：每个候选先判「单次型（造声势）还是周期型（养关系）」——周期型创意（每天/每周/会员日常）别硬塞进单次型活动（开业/发布会/庆典），单次型创意也别伪装成日常运营。撞出来是一回事，**归位到正确的活动类型（时空轴，见 `axes.md` 五）是另一回事**。
- 交叉出 10–20 个候选，挑最反直觉的 3–5 个进收敛标注。

### 热点借势铁律（及时性 + 不短命）

> **借势，不是蹭。** 提取热点背后的「情绪」当燃料，不贴热点标签。

- ❌ 蹭：「蹭某某明星塌房」——贴标签，短命，low。
- ✅ 借势：「塌房背后的集体情绪是对『真诚』的渴望」——提取情绪，喂进情绪域，长效。

**启动顺序**：跑交叉网络前，先按 `search-paths.md` 的热点源（微博热搜 / 抖音热榜 / 新榜日榜）拉当前热点 → 提取每个热点背后的情绪 → 喂进 H 热点域和 E 情绪域。

### 用法（四步）

1. **锁定锚点**：这场活动的核心元素是什么？
2. **拉热点 + 摸情绪**：实时拉热点，提取背后情绪；判断受众此刻的情绪底层。
3. **交叉**：用「嫁接 / 双域碰撞 / 三域撞击」把锚点和变域撞出反直觉候选。
4. **挑反直觉**：从 10–20 个候选里挑最反直觉的 3–5 个，只给「一句概念 + 一句 self-steelman」，进收敛标注。

### 一个走通的例子（发布会）

- **锚点**：悬念。
- **实时拉热点**：假设当下热点是「某综艺靠淘汰赛翻红」。
- **嫁接**：悬念 × 综艺淘汰机制 → 「发布会不公布全貌，观众投票解锁下一个模块」。
- **三域撞击**：悬念 × 情绪(想炫耀) × 感官(嗅觉) → 「凭气味解锁的邀请函」。
- **双域碰撞**：悬念 × 冲突(留白) → 「发布会全程不出现产品正面，揭晓留到最后一秒」。

三个候选，一个锚点 × 三个变域。这就是乘法：组合爆炸，而不是线性组装。

## 三、横纵分析（贯穿全流程的元拆解方法）

> 横纵分析不是「Step 3 发散」的专属工具，是**贯穿全流程的元拆解方法**——任何「需要拆解」的节点都能挂载它：Step 1 拆需求、Step 2 拆目标、Step 3 拆创意、Step 5 拆环节/执行。
> **挂载点由流程节点决定，拆解对象由活动类型决定**（见 `event-types.md` 的「核心要素」），拆解方式统一（纵向演变 + 横向截面）。**按需挂载，不强制**——哪里需要拆哪里才用，不是每个节点都跑一遍。

本节给「问什么」，具体「去哪搜、怎么验证」见 `references/search-paths.md`。别只问不搜。

### 纵向（时间轴）：追这个「拆解对象」的演变史

1. **对象历史**：这个「拆解对象」过去怎么做的？形态演变了什么？
2. **品牌历史**：这个品牌之前做过什么？口碑如何？有没有历史包袱？
3. **翻车案例**：同类做法过去怎么失败的？踩过什么坑？
4. **演变动机**：为什么**在这个时点**会演变出当前形态？

### 横向（同期截面）：切这个「拆解对象」的同类对比

1. **同类做法**：最近同类「拆解对象」怎么做的？「活成了什么样」，不是参数对照。
2. **真实口碑**：评论区、社区里的真实声音（非官方宣传）。实际使用方式和官方定位有没有偏差？
3. **生态位**：这个做法是填补空白，还是正面抢谁的蛋糕？

### 拆解对象怎么定（关键，别用通用清单套）

「拆什么」不是通用环节清单，是**活动类型决定的**：

1. 用 `axes.md` 推导轴定位活动类型
2. 查 `event-types.md` 该类型的「核心要素」——这就是「要拆的环节/对象」
3. 对每个核心要素，做一次上面的纵向 + 横向拆解

例：发布会 → 核心要素「悬念制造 / 峰值体验 / 媒体放大器」→ 分别拆这三个；招商会 → 「信任背书 / 政策刺激 / 逼单节奏」→ 分别拆这三个。用通用环节清单（签到/暖场/高潮/收尾）套 = 模板思维，产出平庸。

### 环节拆解：从案例展示里拆出环节 + 综合（拆「动作」，不是找「环节拆解源」）

案例展示（活动复盘、打卡笔记、案例文章）里就藏着环节信息，虽然不全，但它是这个活动的**对标路径**。环节素材不缺「源」，缺的是「拆」这个动作——**案例展示是原料，横纵分析是加工，综合是产出**。别再去满世界找专门的「环节拆解内容」，把已有的案例展示拆透就够了。

**三步拆法：**

1. **横向逐个拆**：搜 N 个同类案例（N ≥ 3），从每个案例的展示里，拆出它的环节链（预热 → 主体 → 高潮 → 收尾，具体到每个环节做了什么）。
2. **纵向追演变**：挑 1-2 个关键环节（如快闪的「打卡」「稀缺」），追它过去怎么演变。
3. **综合分析**：把 N 个环节链摆一起，拆出三样东西——
   - **共性环节**：这个类型活动的「标配环节」（快闪必有「稀缺 + 打卡 + 社交传播」）
   - **差异创新点**：各案例的差异化设计（茅台的话题势能、泡泡玛特的抽盒仪式感）
   - **环节逻辑**：环节之间的先后因果（为什么「稀缺」要排在「体验」前面）

例（品牌快闪）：拆 10 个快闪案例 → 共性环节 = 预热 → 稀缺 → 体验 → 社交传播 → 转化承接；差异 = 各品牌的创新玩法；逻辑 = 稀缺制造期待 → 体验承接期待 → 传播放大。

### 细化：拆出来的环节，落到「需要哪些内容、细到什么程度」（第二环）

横纵分析拆出的「维度 / 环节 / 模块」是抽象框架，**别停在这**。往下细化一步——每个环节，落到「需要哪些内容条目、细到什么程度」，具体层就是这么来的：

1. **逐个环节细化**：拆出的每个环节（快闪的「稀缺」「打卡」、店庆的「引流」「转化」），问「这个环节要落地，需要哪些具体内容？」——例：店庆「引流」→ 需要「引流渠道（线上/线下）、引流物料、引流优惠、引流目标」。
2. **定颗粒度**：判断这个活动「细到什么程度」——大型活动细到「几点、在哪、谁、多少钱」，轻量活动细到「大概做什么」就行。颗粒度跟着活动规模走，别一刀切。
3. **列内容条目**：每个环节的内容条目，先列「框架」（需要哪些条目），值留空——**框架由横纵分析推导，值由用户填**。

> 关键：具体层 = 「框架」（拆得出）+「值」（问用户）。横纵分析负责生成框架（需要哪些模块、哪些条目、细到什么程度），值交给信息矿填。别把「填不了值」赖成「拆不了框架」——这是两件事。完整链：**拆（维度环节）→ 细化（内容条目+颗粒度）→ 填值（问用户）→ 组装（落成具体表）**。

## 四、信息来源优先级

一手来源优先。多个媒体引用同一错误，会造循环印证假象。

| 信息类型 | 一手来源 | 可信二手 |
|---|---|---|
| 活动案例 | 品牌官方账号、活动回顾、参会者笔记 | 权威媒体原创 |
| 用户口碑 | 小红书/知乎/豆瓣真实评论、现场视频 | 转载聚合（慎） |
| 行业趋势 | 行业报告、协会数据 | 媒体解读 |
| 商业数据 | 官方公告、工商/财报 | 券商研报 |

**硬规则**：关键事实至少两个独立来源，否则标「待验证」。

## 五、信息充分性自检

发散去之前，问三句：

1. 纵向能讲出这个品类/品牌的故事吗？有断层吗？
2. 横向的同类活动清单全吗？漏主要玩家了吗？
3. 关键事实有可靠来源吗？有没有靠单一来源就下判断？
4. 市面信息能不能提炼成可碰撞的信号？如果只得到「某某案例很火」，还没拆到玩法、情绪、审美疲劳、竞品空白，就不能进创意。

答不上来就补搜，别凑合。

## 六、心理机制推理卡（不是名词表，是推理依据）

选 1–3 个当创意支点。**每个机制是一张推理卡，四个字段：理论出处 → 触发条件 → 失效边界 → 反例。** 选机制不是「从名词表里挑一个」，是「哪个机制的触发条件匹配当前场景」。

> 策划的难点从来不是「知道有哪些心理开关」，是「为什么选它、什么条件下它会失效」。只给名词 = 拍脑袋；给了触发条件 + 失效边界 = 推理。

| 机制 | 理论出处 | 触发条件（何时有效） | 失效边界（何时无效） | 怎么用 |
|---|---|---|---|---|
| 好奇缺口 | 信息缺口理论（Loewenstein） | 受众对该主题已有兴趣；缺口「刚好够补」 | 缺口太大=漠不关心；太小=没兴趣；受众对品类零兴趣时彻底无效 | 标题/悬念/不剧透 |
| 社交货币 | 疯传（Berger） | 内容能让分享者显得「内行/有钱/有趣/有品」 | 分享成本高；内容不稀缺、人人可复制 | 打卡点/专属身份/谈资 |
| 稀缺 | 影响力（Cialdini） | 稀缺「真实且外显」：真限量、别人也在抢 | 假稀缺被识破→信任崩塌；供过于求时失效 | 限量/限时/名额 |
| 损失厌恶 | 前景理论（Kahneman） | 受众「已经拥有」后再剥夺（禀赋效应）；已投入沉没成本时最强 | 还没拥有的东西损失厌恶很弱；用于造期待时基本失效 | 倒计时/名额流失提醒 |
| 身份认同 | 社会认同理论（Tajfel） | 有清晰的内/外群体边界，参与能「确认我是谁」 | 圈层模糊、无价值观站队时弱；强加身份被反感 | 圈层暗号/价值观站队 |
| 从众 | 从众实验（Asch）、社会证明 | 不确定情境下、看到「相似他人」在行动 | 确定性情境下从众弱；「相似他人」缺失时弱（大V ≠ 我） | 晒到场/排队/爆满图 |
| 情绪峰值 | 峰终定律（Kahneman） | 能设计一个「无法复制、强烈正情绪」的瞬间 | 峰值平庸=没峰值；只有峰值没有体面终值→记忆被终值拉低 | 设计一个不可复制的高峰瞬间 |

**用法**：先定「受众的情绪底层是什么」，再对表查「哪个机制的触发条件匹配」。机制不是装饰，是创意的受力点。

> **「峰终定律」不是机制，是体验设计原则**：记忆由「峰值 + 终值」决定。它不当创意支点，是 Step 5 体验设计（`references/proposal-schema.md` ③）的指导原则。别把「情绪峰值（机制）」和「峰终定律（原则）」混为一谈。

## 七、动机 → 情绪 → 行为 推理链

推理链是「选机制 + 激发灵感」的工具，不是「每个创意的关卡」。用它验证机制选得对不对，同时从情绪推到行为动作（发散燃料）：

1. **定位情绪底层**：这个受众，现在处于什么情绪状态？（焦虑 / 好奇 / 想炫耀 / 怕落单 / 渴望归属…）
2. **选机制**：用推理卡，找「触发条件匹配当前场景」的机制。不是挑顺眼的，是挑「触发条件成立」的。
3. **推行为**：这个机制触发后，预期受众做什么？（转发 / 到场 / 下单 / 留资…）用哪个设计动作承接这个行为。

**用法边界**：推理链走不通，说明「机制」选错了，换一个重推。它管的是「选机制」，不是「审创意」——发散时别让每个创意回头走推理链，那样创意会被压死。创意的合法性交给 Step 4 对抗去审。

## 八、跨界移植（发散增强角度，防平庸）

当创意陷入「同行怎么做我也怎么做」的平庸时，强制换一个不相干的行业来问：**这个行业怎么解决同一动机？**

| 不相干行业 | 它解决的动机 | 可移植的机制 |
|---|---|---|
| 殡仪业 | 仪式感 / 峰终 | 如何用一场庄重的仪式让人记住一辈子 |
| 游戏业 | 留存 / 上瘾 | 如何设计回访钩子、成长线、社交绑定 |
| 宗教 | 归属 / 峰值 | 如何用反复的仪式制造集体情绪高潮 |
| 赌场 | 损失厌恶 / 逼单 | 如何用「已投入」制造继续参与的冲动 |
| 综艺 | 悬念 / 追看 | 如何用淘汰、晋级、揭晓制造追着看 |

**用法**：发散卡住时，抽一个不相干行业，把它解决同一动机的机制移植过来。移植不是照搬，是「借它的机制，换你的场景」。这是打破「高质量的平均」最有效的一招。

## 九、市场信息碰撞（创意至上增强层）

核心一句话：**市面信息不是拿来抄的，是拿来拆成信号，再和用户资源、活动锚点、心理机制相撞。**

进入 Step 3 发散前，按 `search-paths.md` 找活水。不要把案例原样搬进方案，必须先拆成「可碰撞信号」。

### 1. 四类市面信号

| 信号 | 去哪里拿 | 拆成什么 |
|---|---|---|
| 热点情绪 | 微博热搜 / 抖音热榜 / 新榜日榜 / 平台热议话题 | 受众此刻在兴奋、焦虑、愤怒、怀旧、想炫耀，还是怕落单 |
| 平台玩法 | 小红书 / 抖音 / B站 / 微博的活动笔记、挑战、打卡、评论区 | 哪种拍法、互动、话题、仪式、任务机制正在有效 |
| 竞品空白 | 同类品牌活动、竞品官方号、案例库、用户评论 | 大家都在做什么、什么已经腻了、哪个位置没人占 |
| 用户反向信号 | 小红书评论、抖音评论、微博吐槽、知乎长评、B站弹幕 | 用户觉得尴尬、土、假、高冷、无聊、麻烦、没必要的点 |

**硬规则**：至少拿到 1 个正向信号 + 1 个反向信号。只有正向案例没有反向信号，创意容易变成行业平均值。

### 2. 信号提炼格式

每条市面信息都要改写成这四格，才能进入交叉网络：

| 字段 | 写法 |
|---|---|
| 原始信息 | 看到的热点/案例/评论/玩法，必要时标来源 |
| 底层信号 | 它真正说明的情绪、机制、疲劳或空白 |
| 可用动作 | 能转成什么现场动作、传播动作、互动机制 |
| 失效边界 | 什么情况下会显得硬蹭、过时、廉价或不适配 |

例：

| 原始信息 | 底层信号 | 可用动作 | 失效边界 |
|---|---|---|---|
| 某活动打卡点在小红书爆了 | 用户要的是可证明「我来过」的社交货币 | 设置只在现场生成的身份凭证/限定画面 | 如果所有人都能复制，社交货币失效 |
| 评论区吐槽发布会像领导讲话 | 用户讨厌单向灌输，想参与揭晓 | 把产品信息拆成观众投票/解锁/竞猜机制 | 如果信息太专业，竞猜会变成负担 |

### 3. 六种碰撞公式

用这些公式把市面信息撞成创意，不要只做案例拼贴：

1. **用户资源 × 热点情绪**：把用户已有资源变成承接当下情绪的动作。
2. **活动锚点 × 平台玩法**：把一个流行玩法改造成该活动独有的仪式。
3. **竞品空白 × 心理机制**：别人没占的位置，用一个明确心理机制打穿。
4. **用户反向信号 × 反转设计**：把用户讨厌的点反过来，做成创意主张。
5. **跨界机制 × 市面疲劳**：当同行玩法都腻了，借不相干行业的机制破局。
6. **感官动作 × 传播钩子**：把视觉/听觉/嗅觉/触觉/味觉变成用户愿意拍和讲的理由。

### 4. 创意闪卡输出

每个通过碰撞得到的创意，先只写闪卡，不写完整方案：

| 字段 | 要求 |
|---|---|
| 创意名 | 8–12 字，能被复述 |
| 一句话概念 | 活动到底有什么不同 |
| 信息碰撞 | 标出用的是哪条市面信号 × 哪个用户资源/心理机制/跨界机制 |
| 现场动作 | 至少一个能落地的互动、仪式、体验或内容动作 |
| 传播钩子 | 为什么用户愿意拍、发、讲 |
| self-steelman | 一句说明它为什么可能赢 |

### 5. 禁止项

- 禁止把热点名直接贴到活动主题上；要提取热点背后的情绪。
- 禁止把别人的活动环节照搬；要拆机制再换场景。
- 禁止只看案例文章不看评论区；评论区才暴露真实反应。
- 禁止只输出「高级感、沉浸式、年轻化」这类形容词；必须落到现场动作。
- 禁止为了显得有创意而牺牲主判据；动机错，再新也没用。
